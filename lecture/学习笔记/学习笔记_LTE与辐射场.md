## 1. LTE（局域热力学平衡）到底是什么

### 1.1 先看一个理想的"完全热平衡（TE）"

设想一个**完全孤立、处处温度相同**的气体盒子，放足够久，它会到达终极平衡态（热力学平衡，TE），此时：

- **温度处处相同**（$T$ 均匀）；
- **辐射是完美的黑体** $B_\nu(T)$（光源只由温度决定，与物质细节无关）；
- **物质的微观状态由温度唯一决定**：多少原子被电离用 **Saha 方程**、多少原子处在激发态用 **Boltzmann 方程**、
  粒子速度是 **Maxwell 分布**；
- **每个正过程都被逆过程精确抵消**（细致平衡）：吸收 = 发射、电离 = 复合、上激发 = 下激发，净变化为零。

关键：TE 里"辐射是黑体"与"物质处于平衡"是**同一件事**——因为辐射与物质反复交换能量、最终一致。

### 1.2 LTE 宽松了哪一点、保留了哪一点

现实里气体不可能处处同温（有梯度、有能量往外流）。**LTE 只放弃"温度均匀"，仍要求每个点上物质的状态
服从"该点温度 $T$ 的平衡公式"。**

> **LTE = 在每个小点上，物质（离子化程度、激发布居、速度分布）就是"用该点局域温度 $T$ 套平衡公式"
> 算出来的那个状态。**

| 保留的 | 放开的 |
|---|---|
| 每个点：源函数 = 黑体 $S_\nu=B_\nu(T)$ | 温度随位置、时间变化（**局域**） |
| 每个点：离子化/激发用 Saha / Boltzmann | **辐射场不必是黑体**（能量在流动、有梯度、有净通量） |

为什么这样近似？TE 需要的"辐射 = 黑体"太严格。LTE 说：辐射可以不像黑体，**但只要你每一处的微观过程
（尤其碰撞）足够快、能把物质布居"拽回"局域平衡**，源函数就近于是黑体。这就是"辐射传输里最常用的近似"。

### 1.3 LTE 的核心结论：源函数 = 黑体

辐射转移方程里最关键的量是**源函数** $S_\nu$（发射 ÷ 吸收之比）。在 LTE 下

$$S_\nu=\frac{\eta_\nu}{\chi_\nu}=B_\nu(T),$$

其中 $\eta_\nu$ 是发射系数、$\chi_\nu$ 是吸收系数、$B_\nu(T)$ 是普朗克黑体函数。

**这就是 LTE 的灵魂**：即使辐射场整体不是黑体，**每一处的"发射 ÷ 吸收"之比恰好等于普朗克函数 $B_\nu(T)$**。
在 TE 下这两个量是同一回事；LTE 把这个"比值"保留下来，只把"辐射整体是黑体"去掉。

### 1.4 判断"是否 LTE"：看碰撞 vs 辐射，谁主导

LTE 能成立的前提：**碰撞足够频繁**（原子间、电子间），能把布居"拽"回平衡值，**没有被辐射强行带偏**。

- **密度高、碰撞多** → 碰撞主导 → LTE 容易成立；
- **密度低、碰撞少** → 碰撞拉不住布居 → **辐射就能把布居带离平衡** → LTE 失效，必须做 **NLTE（非 LTE）**。

类比：**碰撞像"粘住"**，把每个原子的电离/激发状态"粘"到平衡值；**辐射像"外力"**，一股很强的光照过来，
能把原子"拽"走（比如把中性原子直接打电离）。粘力够强 → 回平衡（LTE）；外力强过粘力 → 被带偏（NLTE）。

### 1.5 LTE 什么时候失效（本项目三条正好都撞上）

1. **强辐照**：很强能量照过来，光致电离直接把 He II 打成 He III。LTE 公式算出的布居仍是"平衡值"，
   于是**高估了束缚态（He II）的数目和吸收** → 这正是项目说的"LTE He II 光深很大是**警报**，不是
   X-ray 成功"。`[L]`
2. **低密度**：表层密度极低，碰撞太少，气体没时间热化。
3. **变化快**：盘在呼吸（$H(t)$ 变）、轨道相位变化快于热化——还没平衡条件又变了，连"局域静态平衡"都
   谈不上 → 需要**动态**（时间依赖）处理。`[O]`

### 1.6 LTE 在本项目里的具体角色

- **modified blackbody（局部谱）**本质上是 LTE 式假设：每个表面元按 $B_\nu(T_{\rm eff})$（或颜色修正
  $f_{\rm col}$）发射——它隐含"局域热平衡 + 黑体型谱形"。`[A]`
- **Phase 7B3 / 7B4 的"LTE 控制"**：用 Saha 分数、Kirchhoff 源函数 $S_\nu=B_\nu(T)$ 来**验证数字代码没写错**
  （例如"同一组截面下，发射/吸收之比是否严格回到黑体"）。这些是**验收用**，不是结论。`[V]`
- **正式结论**：因上述三条失效原因，项目**不能用 LTE 可信地推出 X 射线**；要可靠就要做 **NLTE**。`[O]`

### 1.7 NLTE（非 LTE）是什么、为什么难

NLTE = **不假设布居服从局域平衡**，而是显式**解统计平衡 / 速率方程**：把每个能级布居当未知量，列出
"光致电离 + 碰撞电离 + 复合 + 碰撞激发……"的**平衡/时间演化方程**，并强制粒子数守恒、电荷守恒。这就要
同时算辐射场 $J_\nu$（布居依赖 opacity、opacity 又反过来决定辐射场）→ **$J_\nu$ ↔ 布居 ↔ opacity 互相反馈
的固定点**，正是 Phase 7B4d 在闭合的那个回路。

> 一句话对比：LTE 用**温度**直接代出的布居；NLTE 要**解方程**求布居。所以 LTE 便宜、NLTE 昂贵但正确。

## 2. 辐射的数据量为什么这么大？它"由什么组成"

核心：这海量数据几乎全是一张**辐射强度 $I_\nu$ 的多维"数字超立方体"**——不是一张图，而是一个多变量的立体表格。

### 2.1 基本量：比强度 $I_\nu$

辐射场最基本的量是 **比强度** $I_\nu$：**在某个点、朝某个方向，每单位频率、每单位立体角、每单位时间
穿过的能量**。单位 ${\rm erg\,s^{-1}\,cm^{-2}\,Hz^{-1}\,sr^{-1}}$（四个字：频率、方向、面积、立体角）。

要"描述整个辐射场"，就得给**每个频率、每个方向、每个位置**各记一个 $I_\nu$ 数字——这就是数据量巨大的根源。

### 2.2 为什么要这么多维度

| 维度 | 为什么需要 | 例子（项目实际规模） |
|---|---|---|
| **频率 $\nu$** | 要得到"光谱"（亮暗随频率变化），必须分辨颜色 | 9632 个频率组（探索时用到 38496） |
| **方向 $\mu$** | 光向四面八方走；要算偏振、临边昏暗、角分布 | 32 个方向（特征分区角求积） |
| **深度/位置 $z$** | 大气里不同深度的强弱、离化不同 | 4096 个深度单元 |
| **时间 $t$（相位）** | 得到"光变曲线"、进动调制 | 2048 个相位点 |

于是强度未知量总数 ≈ 频率 × 方向 × 深度（× 时间）。项目给出一个具体数字：**完整柱的强度未知量 =
9632 × 32 × 4096 = 1,262,485,504 ≈ 12.6 亿个**。`[V]`

### 2.3 为什么"12.6 亿个数"就这么占内存

每个数是 **double 浮点数 = 8 字节**：
- 只存一个 $I_\nu$ 数组 = $1.26\times10^9\times8\ {\rm B}=9.406\ {\rm GiB}$；
- 但要算还得存消光、发射率、温度、布居、几何……一整排类似数组，**合计下界 84.668 GiB ≈ 单机物理内存的
  5.3 倍**。

所以项目不能"一次性全塞进内存"，才要**分块、流式、turning-ray、进程回收**（Phase 7B5u/7B5w/7B6r 那些步骤）。`[V]`

### 2.4 但观测量其实很小

有意思的是：**我们要的最终观测结果其实很小**——远方探测器关心的是**随频率变化的通量 $F_\nu$**
（一条一维"亮度–频率"曲线，加上 $T_{\rm bb}$、$R_{\rm bb}$、偏振、颜色等几个诊断数字）。$F_\nu$ 是把 $I_\nu$
对方向积分（把所有视线方向加起来）、再乘投影面积得到的。

> 为什么**算**它要解析整个场，**看**它却只需要一小条曲线？因为"远方看到什么"是内部所有点贡献叠加的结果
> ——你必须先知道每个点朝观察者方向发出多少、中途被吸收多少，才能加出远方那一条谱。

### 2.5 一个帮助想象的比喻

把辐射场想成一个"**五维超照片**"：
- 通常照片是 2 维（像素 × 像素），记录每像素的亮度和颜色；
- 辐射场是 **3 维空间位置 × 频率（颜色）× 方向（从哪边看它）** 的"超亮暗表"；
- 数据量爆炸是因为把**颜色和方向也当成维**加进去了。

类比：你站在一座楼里，想知道这栋楼在所有天气、所有角度、每个窗户的亮度变化——楼本身 3 维，加上
"窗户透光的方向"和"光是什么颜色"，维度就多了，要记的数就海量。而"远方观察者看到什么"不过是把这海量信息
**压**成一条随颜色变化的曲线。

## 3. 关键词速查

| 术语                   | 一句话                                           |
| -------------------- | --------------------------------------------- |
| **TE**               | 处处同温、辐射=黑体、细致平衡的终极平衡态                         |
| **LTE**              | 每个小点的物质用"该点温度套平衡公式"；源函数 = 黑体；辐射场可非黑体          |
| **NLTE**             | 不假设布居服从平衡，解速率方程（统计平衡）求布居并自洽 $J_\nu$           |
| **源函数 $S_\nu$**      | 发射 ÷ 吸收；LTE 下 $=B_\nu(T)$                     |
| **Saha / Boltzmann** | 电离平衡 / 激发平衡的公式（LTE 下由温度直接给出布居）                |
| **比强度 $I_\nu$**      | 辐射场基本量：点、方向、频率、立体角上的能量密度                      |
| **通量 $F_\nu$**       | 观测所需：$I_\nu$ 对方向积分再乘投影面积（一维曲线）                |
| **$f_{\rm col}$**    | 颜色修正因子（$T_{\rm th}/T_{\rm eff}$），由热化层求出，非自由参数 |
