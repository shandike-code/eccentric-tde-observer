**约定**：新的讨论请**继续追加到该文件**，不要另建散落的问答文件；新增小节按 §10、§11… 顺延编号。

**写法约定**（2026-09-14 定，适用于该文件所有小节）：按**最符合人类认知的脉络**组织——先写
"读到哪儿会卡住、为什么这是个问题"，再按"为什么需要 → 怎么得到 → 怎么自己验一遍"展开；
**不指明代码出处**（不写文件路径、行号、函数名、变量名），只保留物理与逻辑；但**必须具体**，
给出公式、符号含义、真实数值与可自查的检验，不用"可以证明""显然"这类含糊话。数值可以标明
出自哪个阶段（如 Phase 3 / Phase 4），因为那是论证的一部分。

## 4. 给新 AI 会话的建议流程

1. 读本页，确认文档地图与讨论记录位置；
2. 若任务与**科学内容/讲义**有关：读
   [[eccentric_tde_observer/lecture/项目讲义/01_项目整体讲义_改进版|改进版讲义]]，
   并先扫一遍 [[eccentric_tde_observer/lecture/学习笔记/讲义讨论_常见疑问澄清|讲义讨论]] 以免重复已澄清的问题；
3. 若任务涉及**证据标签与双链规范**：读
   [[eccentric_tde_observer/docs/obsidian_linking_standard|Obsidian 双链与讲义文档规范]]；
4. 若任务需要历史任务书的口径与"必须准确使用的数值"：读 `claude_lecture_brief.md`；
5. 产出后：把**讨论/澄清类**内容追加到讲义讨论文件，把**成果类**内容放进 `项目讲义/`，
   不要在 `AI任务简报/` 里写科学结论。
