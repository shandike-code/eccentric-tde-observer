# Phase 7B6r：短寿命工作进程关闭固定物质全柱门

上游：[[phase7b6q_resource_recheck|Phase 7B6q 资源复验失败]]

## 架构边界

7B6r 不改变输运方程、频率网格、角度网格、深度网格或形式通量定义。76 块仍只允许两个进程
同时运行，但改由四个逻辑进程分两批处理，每个进程只承担 19 块；第一批退出并释放内存后才
启动第二批。`[A-preregistered]`

## 当前授权

7B6r 正式建立：在固定物质、单个最坏相位、9632 组、32 方向和 4096 辐射深度单元上，
相邻状态的正式出射谱与总通量达到 $10^{-3}$ 科学门，且可在本机资源上确定性复现。[V]

它只授权下一项**单次、有界物质反馈 pilot**，不等于代数残差达到 $10^{-10}$，也不授权完整
2048 相位轨道、Phase 4 替换或 UVOT。`[O]`
