# Phase 7B5u：完整动态柱资源与特征线准入审计

预注册：[[phase7b5u_preregistered_full_column_admission|Phase 7B5u 预注册]]  
上游：[[phase7b5t_characteristic_transport_gate|Phase 7B5t 特征输运门]]

## 1. 结论

[V] 审计完整性通过，但当前整体完整柱路径未获准运行。原因不是单一的 CPU 等待时间：

- 正式网格含 1,262,485,504 个强度未知量；一份强度数组为 9.406 GiB；
- 当前实现已识别的九类同时驻留三维数组合计至少 84.668 GiB，是本机 16 GiB 物理
  内存的 5.292 倍；这一数值还没有计入二维物质数组、搬移临时量和返回诊断；
- 2048 个相位中有 586 个相位出现 ALE 特征线反向，占 28.613%；
- 反向只涉及 $\mu=\pm0.00529953$ 两个最掠射方向，每个受影响相位的合计角权重占
  全角积分的 1.3576%。比例虽小，但不能删除或事后重归一化。

因此下一阶段必须同时完成：有界内存的全局频率流式分块，以及守恒的 turning-ray
处理。[O] 两者都通过独立等价性与收敛测试以后，才可运行生产完整柱。

## 2. 输入完整性

以下检查全部通过 [V]：

- 相位数严格为 2048；
- 完整物质柱严格为 256 单元，辐射深度严格为 4096；
- 所有相位步长均有限且严格为正；
- 中面位置和镜像物质场保持在预注册容差内；
- 物理、碰撞和外层频率组数分别为 9632、9634 和 9636。

最短相位步长是真近心点附近的非均匀时间采样，不是被删除的坏点；本审计保留了全部
2048 个相位。

## 3. 内存账本

正式强度数组元素数为

$$
9632\times32\times4096=1{,}262{,}485{,}504.
$$

双精度下单数组占

$$
1{,}262{,}485{,}504\times8\ {\mathrm{byte}}
=9.40625\ {\mathrm{GiB}}.
$$

源代码活跃集下界为 84.668 GiB，已远高于 12 GiB 的预注册准入线。直接运行很可能进入
交换空间或被系统终止，不能得到可信的性能或科学结果。

资源探针显示：128、256、512 和 1024 个核心频率组对应的已识别活跃集分别约为
1.135、2.260、4.510 和 9.010 GiB。由于这些数字仍未包含搬移临时量，下一阶段从
256 组开始测量真实峰值；这只是 [A-computational] 起点。

## 4. 特征线反向

32 方向特征分区求积的最小绝对方向余弦为
$|\mu|_{\min}=0.00529953$，而完整轨道的最大 ALE 网格面速度为
$|w|/c=0.00802860$。当网格面速度跨过 $c\mu$ 时，同一条离散射线在柱内不再能用单向
扫掠表示。

只有两个最掠射节点受到影响，但它们在 586 个相位中反向。旧的一阶迎风有限体积算子能
守恒处理变号通量，却未达到 7B5t 的深度精度；单元特征算子精度足够，却要求方向不变。
下一阶段需要把两者的作用域明确分开，并用制造解和实际相位加密证明混合处理不会污染
正式观测量。

## 5. 图像逐图解释

![Phase 7B5u full-column admission](../outputs/phase7b5u_full_column_admission.png)

- **(a) Current solver memory admission**：蓝柱为 16 GiB 物理内存，虚线为 75%
  准入线；红柱仅为已识别活跃集下界，已达 84.668 GiB，所以整体路径明确失败。
- **(b) Grazing-ray reversal condition**：橙线是每相位最大网格面速度，虚线是最小
  $|\mu|$。橙线越过虚线的相位需要 turning-ray 处理。
- **(c) Phases requiring turning-ray treatment**：反向集中在两段近心点邻域；峰值
  1.3576% 是两个掠射节点的全角权重分数，不表示可以忽略它们。
- **(d) Bounded-memory block sizing**：活跃集随块宽近似线性增长。256 组位于
  6 GiB 探针线以下，适合作为首次实测块宽；512 组仍需实测临时数组后再决定。

## 6. 科学边界

- [V] 已证明当前整体实现不适合本机资源，并定位了反向射线的相位与角节点；
- [A-computational] 256 组只是实现探针，不改变正式 9632 组物理频率预算；
- [O] 尚未产生完整柱动态连续谱，也尚未替换 Phase 4；
- 本阶段没有修改 ZO 动力学、物质背景、频率预算或连续谱物理闭合。
