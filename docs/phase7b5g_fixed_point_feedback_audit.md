# Phase 7B5g：H I 率误差在碰撞固定点中递推放大

> [!summary] 阶段结论
> `[A/V/O]` Phase 7B5g 以只读观察器保存 P1 与 P0 固定点的第 0、1、2、4、8 次和收敛
> 状态，不改变求解器。第 0 次逐位复现 7B5f，收敛状态逐位复现 7B5e。最大速度状态到
> 第 2 次才超过最终误差的 $50\%$，最大宽度变化状态到第 8 次才超过；最终 H I 率差相对
> 第 0 次分别放大 $1.79\times10^{4}$ 与 $3.12\times10^{4}$。同时，绝对差的主导能段
> 从 H I shoulder 逐步转到 Doppler 阈值带。因此主误差不是第一碰撞更新瞬时写入，而是
> 真实碰撞--Lorentz 固定点的递推放大。下一步授权递推放大审计，不授权拆第一步后直接
> 修消光/发射率，也不选择生产频率表示。

## 1. 只读固定点截面

P0 和 log-P1 求解器新增默认关闭的 `iteration_observer`。观察器在第 0 次接收初值，并在
每次正性更新后接收只读视图；它不能改写内部数组，正式默认路径完全不变。[V]

保存的 `[A-control]` 检查点为

$$
n=0,1,2,4,8,\mathrm{converged}.
$$

每个检查点都重新执行相同的实验室系到共动系强度搬移，并独立复算：[V]

1. 共动能量积分；
2. H I 总光致电离率；
3. H I Doppler 带、shoulder 和更高能段的有符号/绝对差；
4. lab 与共动 log-P1 饱和组数；
5. 共动搬移 limiter 次数；
6. 8/16 阶并集边界求积一致性。

第 0 次相对 7B5f、收敛状态相对 7B5e 的差均为 0；观察器没有改变端点解。[V]

## 3. 阈值主导区的迁移

![Phase 7B5g H I region evolution](../outputs/phase7b5g_region_evolution.png)

**左图。** 最冷表层在全部迭代中仍由 H I shoulder 主导，比例约 $85\%$--$88\%$；它的
错误增长主要改变幅度，不改变能段性质。[V]

**中图。** 最大速度从第 0 次 shoulder 占 $93\%$，经第 1 次的 $60\%$，到第 2 次
Doppler 带占 $56\%$；第 4 次以后稳定在 $62\%$。误差达到最终值一半与主导区转成
Doppler 带发生在相近迭代。[V/O]

**右图。** 最大宽度从第 0 次 shoulder 占 $92\%$，第 2 次 Doppler 带已占 $57\%$，
第 4 次为 $81\%$，第 8 次为 $89\%$，收敛时为 $91\%$。这里能段迁移早于幅度达到
$50\%$，说明阈值误差模式先建立，再被递推放大。[V/O]

## 4. limiter 与能量是否单独解释增长

第 0 次 lab 初值有约 964--968 个饱和组；第一次传输更新后 lab 饱和组数变为 0，但 H I
率误差反而开始增长。故“初值饱和组持续存在”不是递推误差的解释。[V]

共动饱和组在最大速度状态为 0，而其 H I 率仍放大 $1.79\times10^{4}$；最大宽度状态的
共动饱和组只从约 53 缓慢增至 59，率误差却增加两个数量级。limiter 可能参与谱形演化，
但单一饱和组计数不能解释两种移动状态的增长率。[V/O]

候选--参考共动能量误差也随迭代增长，但收敛时分别只有
$6.48\times10^{-7}$、$3.71\times10^{-6}$ 和 $1.55\times10^{-4}$。H I 率对阈值谱形比
总能量更敏感，不能用全频能量账本替代率门。[V]

下一小阶段应在不改固定点的条件下估计 P1 与 P0 源迭代映射的局域误差放大：[A/O]

$$
\delta J^{(n+1)}
\simeq
\mathcal M^{(n)}\delta J^{(n)}
+
b^{(n)}.
$$

需要区分每步新注入误差 $b^{(n)}$ 与已有误差被传播的放大矩阵 $\mathcal M^{(n)}$。可先用
匹配参考状态上的有限扰动/Jacobian--vector 产品和制造谱测试，不需要构造完整稠密 Jacobian。
在这一步前，不应把慢增长解释成物理不稳定性；它仍可能只是两种频率离散的固定点映射不同。
[A/O]

角度、辐射子网格、整轨道、物质反馈、Phase 4 替换和 UVOT 继续关闭。[A/V/O]
