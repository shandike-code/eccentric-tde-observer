# Phase 7B7c：物质响应时间尺度和深度定位

上游：[[phase7b7b_material_response|Phase 7B7b 信赖域失败]]

## 诊断定义

对每个半柱父单元定义 10% 物质能响应时间

$$
t_{0.1}
=
0.1\frac{\rho e_{\rm mat}}{\left|Q_{\rm rate}\right|}.
$$

它只用于判断完整相位步能否把辐射场冻结，不把缩短后的时长实际应用到状态。`[A]`

## 结果

| 量 | 结果 |
|---|---:|
| 最短 $t_{0.1}$ | $9.3951\,\mathrm{s}$ |
| 限制单元的表面质量分数 | $0.0043447$ |
| 实际相位步 | $889.4199\,\mathrm{s}$ |
| 仅按物质能 10% 门得到的最少子步下界 | $95$ |
| $t_{0.1}<\Delta t$ 的柱质量比例 | $17.819\%$ |
| $t_{0.1}<\Delta t/10$ 的柱质量比例 | $5.636\%$ |
| 柱积分净加热/吸收或发射功率 | $3.3223\times10^{-4}$ |

吸收与发射柱功率分别约为 $1.21396\times10^{16}$ 和
$1.21355\times10^{16}\,\mathrm{erg\,s^{-1}\,cm^{-2}}$，净加热只是两个大项的小差。
但净加热又与独立四力路径通过 $10^{-3}$ 门，因此不能把快速热响应简单归为一个坏频率 bin。
