# Phase 7B5u：完整动态柱准入门预注册

上游：[[phase7b5t_characteristic_transport_gate|Phase 7B5t 特征输运门]]  
执行报告：[[phase7b5u_full_column_admission|Phase 7B5u 完整动态柱准入审计]]

## 1. 目的与证据边界

Phase 7B5t 已在单物质单元上接受 9632 个物理频率组、32 个方向、每个物质单元
16 个辐射子单元和守恒单元特征积分。7B5u 不运行完整动态柱，而是在运行前冻结两个问题：

1. 当前整体数组实现能否放入本机内存；
2. 完整柱的 ALE 网格速度是否会使已接受角节点在柱内反向。

这是 `[A-preregistered]` 机器准入协议。输入完整性与全相位几何统计属于 `[V]`；尚未
实现的流式求解器属于 `[O]`。

## 2. 冻结输入

- 7B5t 结果：`outputs/phase7b5t_characteristic_transport_summary.json`；
- N128、2048 相位物质参考：`outputs/phase7b4r_depth128_phase2048.npz`；
- 9632 组主频率网格：`outputs/phase7b5p_master_worker_input.npz`；
- 当前混合系 ALE 与角求积实现。

全部文件在预注册 JSON 中记录 SHA-256。完整双面柱固定为 256 个物质单元；每个物质
单元 16 个辐射子单元，因此辐射深度为 4096。

## 3. 内存门

正式强度未知量数为

$$
N_{\rm I}=9632\times32\times4096.
$$

内存账本只计入当前源代码在一次单元特征更新末端仍同时存活的九类三维数组：初态、
外守护模板、消光、当前迭代、外网格工作量、共动角强度、实验室系发射率、更新强度和
界面强度。二维物质数组、频率搬移临时量和最终诊断数组不计入这个下界。

整体路径只有在这一下界小于物理内存的 75% 时才准入。若失败，下一步必须保留完整全局
频率网格，使用有界内存流式分块；不能减少频率组冒充解决资源问题。

## 4. 特征线方向门

中心固定的镜像完整柱令角分区点为 $\mu_{\rm split}=0$。对每个相位、每个角节点和全部
网格面计算

$$
a_{m,f}=c\mu_{m}-w_{f}.
$$

如果同一角节点的 $a_{m,f}$ 在柱内跨越零，纯单向单元特征扫掠便不成立。正式准入要求
全部 2048 个相位均无反向。若失败，下一步必须建立并单独验证守恒的 turning-ray
处理；禁止删除掠射角节点或把其权重重归一化。

## 5. 决策规则

- 内存门失败：进入保留全局频率边界的流式分块；
- 特征线方向门失败：加入单独验收的守恒 turning-ray 算子；
- 两项修正都通过独立门以后，才准许正式完整柱运行；
- 256 个核心频率组只是第一轮资源探针 `[A-computational]`，不是已接受的生产块宽。
