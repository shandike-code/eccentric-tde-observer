## 1. 本阶段只回答一个问题

Phase 7B4n 已证明 1024 相位下 N=62 对有限 N=64 参考的空间门通过，但 N=64 的 512 对
1024 最大逐点人口差为 $1.087\times10^{-3}$，略高于预声明的 $10^{-3}$ 生产门。Phase
7B4o 因而保持 N=64 深度网格、71 个实际频率点和全部物理闭合不变，独立求解 2048 相位
周期解，再直接比较 1024 对 2048。`[V]`

本阶段没有实现激发态、总复合级联、非局域频率依赖动态转移、速度--频率耦合、观察者谱、
Phase 4 大气替换或 UVOT 仪器层。通过本阶段只表示当前局域
$J_{\nu}=B_{\nu}(T)$--Rosseland 动态柱的有限时间离散门关闭。`[A/V/O]`

## 2. 独立参考与比较定义

2048 相位解从与 7B4n 相同的 16 层父初态守恒延拓到 N=64，没有从 1024 相位周期解热启动，
也没有把 1024 解插值后当成新解。每个完整轨道结束后才保存检查点；相位数、深度边界和
频率网格必须逐位一致才能恢复。`[V]`

比较时只把较粗的独立解周期线性插值到较细参考的真实轨道时间相位。对温度、Rosseland
opacity 和表面能流使用最大相对误差

$$
\epsilon_{\rm X}
=
\max_{k,j}
\frac{\left|X_{\rm coarse}(\phi_{k},m_{j})
-X_{\rm ref}(\phi_{k},m_{j})\right|}
{\left|X_{\rm ref}(\phi_{k},m_{j})\right|},
$$

对 H II 与 He III 布居使用最大绝对误差

$$
\Delta x
=
\max_{k,j}
\left|x_{\rm coarse}(\phi_{k},m_{j})
-x_{\rm ref}(\phi_{k},m_{j})\right|.
$$

柱平均量使用单元质量权重；He III 半电离前沿另行比较状态和质量分数位置。所有连续指标
必须严格小于 $10^{-3}$，前沿状态错配相位数必须为 0。`[A-classification/V]`

## 3. 正式 64×2048 周期解

| 量 | 64×2048 结果 | 判据 |
|---|---:|---:|
| 实际频率点 | 71 | 与 7B4n 相同 |
| 完整周期数 | 2 | 至周期收敛 |
| 运行时间 | $2269.40\ \mathrm{s}$ | 实测值 |
| 最终周期残差 | $4.114\times10^{-10}$ | $<2\times10^{-7}$ |
| 周期能量账本相对残差 | $1.111\times10^{-11}$ | $\ll10^{-3}$ |
| 初态与限制守恒 | 通过 | 每项 $<2\times10^{-12}$ |

求解器需要 2 个完整周期才满足周期门；第一周期只作为恢复点，不能冒充正式结果。最终周期
同时关闭了周期状态和能量账本；两者是独立诊断。正式 NPZ 的 17 个数值数组和两份
JSON 已逐项检查为有限值，完成后没有遗留检查点。`[V]`

## 4. 512--1024--2048 时间收敛

| 指标 | 512 对 1024 | 1024 对 2048 | 有限误差缩减 | 目标 |
|---|---:|---:|---:|---:|
| 表面能流相对误差 | $5.457\times10^{-4}$ | $1.660\times10^{-4}$ | 3.29 | $10^{-3}$ |
| 最大逐点 $T/\kappa_{\rm R}$ 相对误差 | $1.069\times10^{-4}$ | $3.505\times10^{-5}$ | 3.05 | $10^{-3}$ |
| 最大逐点 H II/He III 绝对误差 | $1.087\times10^{-3}$ | $2.887\times10^{-4}$ | 3.77 | $10^{-3}$ |
| 最大柱平均 $T/\kappa_{\rm R}$ 相对误差 | $9.182\times10^{-5}$ | $2.910\times10^{-5}$ | 3.16 | $10^{-3}$ |
| 最大柱平均 H II/He III 绝对误差 | $1.127\times10^{-4}$ | $3.923\times10^{-5}$ | 2.87 | $10^{-3}$ |
| He III 前沿质量分数误差 | $9.801\times10^{-5}$ | $3.486\times10^{-5}$ | 2.81 | $10^{-3}$ |
| 前沿状态错配相位数 | 0 | 0 | -- | 0 |

1024 对 2048 的全部指标通过，且已知最敏感的逐点人口误差从门槛上方降到
$2.887\times10^{-4}$。表中的缩减因子只是两次有限网格最大误差之比；最大误差位置可能
移动，所以不把它解释成严格渐近收敛阶，也不声称 2048 相位是连续极限。`[A/V]`

最大 H II 误差为 $2.131\times10^{-8}$，位于轨道相位 $0.52695$、深度索引 1。最大 He III
误差仍位于回到近心点前的快速响应区：轨道相位 $0.98875$、最表层深度索引 0、质量分数
中心 $7.899\times10^{-4}$；1024 插值值和 2048 参考值分别为 $0.199426$ 与 $0.199138$。
该敏感位置没有被删除或平滑。`[V]`

下一微阶段应在这个有限 N=64、2048 相位参考上，把局域
$J_{\nu}=B_{\nu}(T)$--Rosseland 闭合替换为非局域、频率依赖的动态转移。第一步仍应保留
当前 H/He 基态和规定 ZO 背景，先关闭辐射能量、粒子数、高光深扩散与周期性极限，再决定
是否加入激发态。不能把本阶段的准入结果写成“动态 NLTE 输出谱已经完成”。`[A/V/O]`
