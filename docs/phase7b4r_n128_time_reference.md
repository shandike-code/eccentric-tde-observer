## 1. 为什么必须独立运行 N128×2048

Phase 7B4q 已把物质深度提高到 N128，并关闭冻结形式解的频率、角度和辐射子网格门；但
只有 N128×1024 周期物质解。N64 上的时间门通过不能证明 N128 上也通过，因为表层移动
He III 前沿对深度和时间离散都敏感。[V/O]

本阶段因此从同一个 N16 静态父初态直接守恒延拓到 N128，并在 2048 个轨道相位上重新求解
完整周期。它没有读取 N128×1024 的终态，也没有把 1024 相位结果插值后冒充独立参考。
相位仍定义为

$$
\phi_{k}
=
\frac{t_{k}-t_{\rm peri}}{P_{\rm orb}},
\qquad
0\le\phi_{k}<1.
$$

为只隔离时间轴，两个 N128 算例都保留相同的 71 点局域 Planck--Rosseland 动态闭合；
Phase 7B4q 的 160 点阈值求积和辐射子网格没有混入本阶段物质时间比较。[A/V]

## 2. 独立参考本身是否闭合

N128×2048 从独立静态初态运行两个完整周期，最终残差为
$3.839\times10^{-10}$，低于 $2\times10^{-7}$ 周期门。最终结果为：

| 量 | N128×2048 |
|---|---:|
| 总周期数 | 2 |
| 运行时间 | $4675.4\ {\rm s}$ |
| 周期残差 | $3.839\times10^{-10}$ |
| 最大局域能量残差 | $1.352\times10^{-11}$ |
| 周期能量账本残差 | $1.088\times10^{-11}$ |
| 最大初态/限制守恒残差 | $9.063\times10^{-16}$ |
| 温度范围 | $9363.6$--$107633.7\ {\rm K}$ |

未完成的相位片段不被当作科学结果；最终文件原子写入后检查点已删除。
没有使用 nan_to_num、任意 clip、任意 floor、失败相位删除或事后物理重归一化。[V]

## 3. 1024 对 2048 的联合时间门

N128×1024 候选被周期插值到 2048 个参考相位。正量 $x$ 使用最大相对误差

$$
\epsilon_{\rm rel}(x)
=
\max_{k,j}
\frac{
\left|x_{1024}(\phi_{k},j)-x_{2048}(\phi_{k},j)\right|
}{
\left|x_{2048}(\phi_{k},j)\right|
},
$$

离子分数使用最大绝对误差。表面能流、逐点温度/opacity、逐点 H II/He III、柱平均量和
He III 半电离前沿全部要求小于预声明的 $10^{-3}$，且前沿状态必须零错配。[A/V]

| 联合指标 | 1024 对 2048 | 判定 |
|---|---:|---|
| 表面能流相对误差 | $1.660\times10^{-4}$ | 通过 |
| 最大逐点温度/opacity 相对误差 | $3.511\times10^{-5}$ | 通过 |
| 最大逐点人口绝对误差 | $2.911\times10^{-4}$ | 通过 |
| 最大柱平均温度/opacity 相对误差 | $2.913\times10^{-5}$ | 通过 |
| 最大柱平均人口绝对误差 | $3.926\times10^{-5}$ | 通过 |
| He III 半电离前沿位置误差 | $3.417\times10^{-5}$ | 通过 |
| 前沿状态错配相位数 | 0 | 通过 |

最差逐点人口是相位 $0.98895$、最表层质量单元的 He III，候选与参考分别为 $0.1974401$
和 $0.1971490$。最大温度误差位于相位 $0.91814$、深度单元 43；最大 Rosseland opacity
误差位于相位 $0.98875$、最表层单元。所有失败敏感区域都被保留，没有删除近心点相位。

## 4. N128×2048 物质场说明了什么

![Phase 7B4r material reference](../outputs/phase7b4r_reference_map.png)

- 面板 (a) 显示温度在表层最低，并在近心点附近迅速升高；它来自局域动态能量柱，不是
  观察者颜色温度表。
- 面板 (b) 显示 He III 半电离前沿在远近心点之间穿过约 $0$--$0.5$ 的半柱质量分数；
  这解释了为什么逐点人口比柱平均量更难收敛。
- 面板 (c) 显示出射能流相对瞬时 ZO 耗散存在相位滞后和约百分之一幅度的热记忆；这不是
  非局域辐射储能，因为当前能流仍由局域 Rosseland 扩散闭合计算。
- 面板 (d) 中 H 基本完全电离，而柱平均 He III 随轨道在约 $0.60$--$1.00$ 间变化；这仍
  只是基态 H/He 局域闭合的条件结果。

## 5. 阶段决定

Phase 7B4r 关闭了 N128 有限物质参考的深度--时间门：N128×1024 可继续作为当前局域闭合
物质候选，N128×2048 是时间参考。由于 Phase 7B4q 的冻结形式频率、角度和辐射子网格门
也已通过，下一小阶段获准建立动态非局域辐射耦合器。[A-classification/V]

但 Phase 7B4p 的

$$
\max\left(\frac{t_{\rm diff}}{P_{\rm orb}}\right)=0.7379
$$

没有因本时间门而改变。逐相位稳态辐射近似仍失败；下一阶段必须显式演化辐射储能或等价的
时间依赖强度矩，而不是重复冻结形式解。当前仍不授权：[O]

1. 用本局域闭合物质场替换 Phase 4；
2. 生成物理动态 NLTE 连续谱；
3. 进入 UVOT 仪器层；
4. 接 Cloudy 生成真实线发射；
5. 声称已经闭合激发态、总复合级联、线转移、Compton 重分布或速度频率耦合。

## 6. 文件与复现

核心文件：

- scripts/phase7b4r_n128_time_reference.py：独立参考、联合时间门、误差定位和英文图；
- tests/test_phase7b4r_n128_time_reference.py：路径隔离、联合门、误差定位和禁用修复测试；
- outputs/phase7b4r_depth128_phase2048.npz：完整 N128×2048 物质场；
- outputs/phase7b4r_summary.json：机器可读阶段判定；
- outputs/phase7b4r_time_convergence.csv：预声明联合时间指标；
- outputs/phase7b4r_error_locations.csv：各连续场最差相位和深度；
- outputs/phase7b4r_reference_phase.csv：逐相位参考摘要；
- outputs/phase7b4r_time_convergence.png、outputs/phase7b4r_reference_map.png：英文图。

复用已经完成的参考与汇总可运行：

~~~bash
.venv/bin/python scripts/phase7b4r_n128_time_reference.py --stage all
~~~

只有显式加入 --force 才会删除并重算本阶段对应产物。[V]
