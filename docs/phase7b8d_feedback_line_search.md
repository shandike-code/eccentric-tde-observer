# Phase 7B8d：反馈感知的受保护残差回溯

上游：[[phase7b8c_secant_feedback|Phase 7B8c 割线真残差失败]]

## 问题定位

7B8c 中上一最难单元的有符号残差在当前态和完整割线端点之间换号。这说明完整割线对该
单元发生过冲，但不能据此假定中间态的辐射反馈线性。7B8d 只把两个已经完成全频映射的
端点残差作仿射预测，用于选择一次待验证的回溯步。`[A-preregistered/V/O]`

对预注册候选 $\lambda\in\{0.25,0.50,0.75\}$，预测残差为

$$
R_{k}^{\rm pred}(\lambda)
=
(1-\lambda)R_{k}^{\rm current}
+
\lambda R_{k}^{\rm endpoint}.
$$

物质比能和 H/He 分数也只作凸组合；温度由组合后的比能直接反演。没有逐点裁剪、floor、
事后重归一化或重复累计物理时间。`[V]`
