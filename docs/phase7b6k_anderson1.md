# Phase 7B6k：深度一 Anderson 加速严格失败

上游：[[phase7b6j_positivity_line_search|Phase 7B6j 正性边界线搜索]]  
后续：[[phase7b6l_anderson2|Phase 7B6l 深度二 Anderson 门]]

## 目的与边界

Phase 7B6j 表明标量松弛已到整态非负性的边界。7B6k 因而在同一个最坏全深度频率块上预注册
低存储 Anderson(1)，比较对象仍是 16 次源映射的 Phase 7B6g 向量 Aitken；不改物质状态，
不进入全频率或全轨道计算。`[A-preregistered]`

令固定点残差为

$$
R_{k}=G(I_{k})-I_{k}.
$$

深度一 Anderson 只保留相邻两次状态和残差，并用整个状态的单一线搜索系数保护有限性与非负性。
没有逐单元裁剪、强度 floor、失败点删除或事后重归一化。`[V]`

## 冻结门槛与结果

预注册要求同成本末次残差相对向量 Aitken 严格低于 $0.5$。实测：

| 量 | 结果 |
|---|---:|
| 末次原始固定点残差 | $1.6784391\times10^{-5}$ |
| 独立审计残差 | $1.4807480\times10^{-5}$ |
| 相对向量 Aitken | $1.4751432$ |
| Anderson 步完整接受数 | $15/15$ |
| 最小强度 | $3.93033\times10^{-7}$ |
| 总运行时间 | $99.22\,\mathrm{s}$ |
| 峰值 RSS | $5012.55\,\mathrm{MiB}$ |

全部 Anderson 提案均完整接受，说明失败不是正性线搜索截断造成；它在该块上反而比向量 Aitken
慢约 $47.5\%$。因此 7B6k 严格失败，未启动全频率 Anderson(1)。`[V]`

## 结论

7B6k 是有信息量的失败：深度一历史不足以压低这个最坏块的慢模。它只授权一次预先限定的
Anderson(2) 终局局域门，不授权继续扫描历史深度或调参。`[O]`
