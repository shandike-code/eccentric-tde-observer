# Phase 7B6q：资源复验再次失败

上游：[[phase7b6p_final_formal_flux|Phase 7B6p 科学门通过、资源门失败]]  
后续：[[phase7b6r_worker_recycling|Phase 7B6r 短寿命工作进程]]

## 目的

7B6q 只重复 $I_{29}$ 的正式形式输运，并与 7B6p 保存的 $I_{29}$ 正式谱逐位比较；$I_{30}$
结果直接读取冻结报告。不改变物理输入、块划分、两进程并发或 6 GiB 门。`[A-preregistered]`

## 结果

重复正式谱的最大绝对差为 0，科学指标仍为谱 $L_{1}=5.05401\times10^{-4}$、总通量变化
$4.33885\times10^{-4}$。但两个进程的峰值 RSS 为 6421.66 和 6276.58 MiB，均超过
6144 MiB；墙钟 357.76 s 通过。`[V]`

![Phase 7B6q resource recheck](../outputs/phase7b6q_resource_recheck.png)

图 (a) 显示科学量继续过门；图 (b) 明确显示两个长寿命进程均越过资源线；图 (c) 表明墙钟
不是失败来源。逐位复现排除了物理解改变，重复超门则排除了单次偶然内存抖动。`[V]`

## 判定

7B6q 严格失败。证据把问题定位为每个进程连续处理 38 个异质频率块时的内存高水位累积，
因此只授权一次保持两并发、但把每个逻辑进程寿命缩短到 19 块的资源终局门；不授权继续重复
同一架构直到碰巧通过。`[A-preregistered/O]`
