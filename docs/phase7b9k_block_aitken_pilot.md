# Phase 7B9k：自然频率块 Aitken 加速门失败

上游：[[phase7b9j_finite_trial_cost_decision|Phase 7B9j 有限试探内层辐射成本门]]

## 预注册设计

7B9k 保持有限物质候选、$9632$ 个频率组、32 个方向、4096 个深度单元和原来的 76 个
自然输运块不变。第 4 次映射采用整块有限且非负的最大安全回退权重；第 5--6 次对每个
自然频率块分别计算

$$
\omega_{b,n}
=
-\omega_{b,n-1}
\frac{\left\langle r_{b,n-1},r_{b,n}-r_{b,n-1}\right\rangle}
{\left\|r_{b,n}-r_{b,n-1}\right\|_{2}^{2}}.
$$

只有正有限、整块保持非负且不超过历史全频实际接受上界 $5.8709504$ 的候选才被接受；
否则按 $2.0,1.8,1.5,1.2,1.0$ 的冻结顺序整块回退。没有逐点裁剪、强度 floor、坏点删除、
`nan_to_num` 或事后重归一化。协议 SHA256 为
`af4f6c36bb9941dc1f676250c6ea911c39cf31ad655b346da8bf7d9b06f719fc`。`[A-preregistered/V]`

## 决策边界

停止自然频率块标量 Aitken，也不恢复 $\omega=1$ 朴素续算。7B9k 只否决当前内层加速器
与预算组合；它不物理拒绝有限物质候选，不单独拒绝静态近似，也不是动态 NLTE 解。
下一步必须改变算子层级，例如把单次块 Jacobi 映射替换为受控的块内隐式/多次散射求解，
并先做代表频率块成本--收缩门。候选辐射内收敛、正式 H/He 反馈和真残差完成前，仍不进入
Phase 4 替换、UVOT 或真实线形成。`[V/O]`
