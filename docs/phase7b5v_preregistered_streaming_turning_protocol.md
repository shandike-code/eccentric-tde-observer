# Phase 7B5v：流式频率块与 turning-ray 算子预注册

上游：[[phase7b5u_full_column_admission|Phase 7B5u 完整柱准入审计]]  
执行报告：[[phase7b5v_streaming_turning_gate|Phase 7B5v 算子门]]

## 1. 目的

7B5u 已证明正式完整柱不能使用当前整体数组实现，并发现两个最掠射方向在部分相位中
反向。7B5v 冻结两个数值修正 `[A-preregistered]`：

1. 非反向方向继续使用单元特征积分；反向方向使用守恒隐式迎风三对角系统；
2. 9632 个正式频率控制体保持不变，只把计算分成核心块，并从同一全局网格取得两次
   Lorentz 搬移所需的精确 halo。

禁止删除掠射方向、重归一化角权重或缩减正式频率预算。

## 2. turning-ray 门

若面相对速度 $a_{f}=c\mu-w_{f}$ 在柱内变号，离散方程写为

$$
\frac{\Delta z_{i}^{n+1} I_{i}^{n+1}-\Delta z_{i}^n I_{i}^n}{\Delta t}
+a_{i+1/2}I_{i+1/2}^{\rm up}
-a_{i-1/2}I_{i-1/2}^{\rm up}
=c\Delta z_{i}^{n+1}(\eta_{i}-\chi_{i} I_{i}^{n+1}).
$$

它构成三对角 M 矩阵。预注册要求：与独立稠密矩阵解的最大差、联立残差和能量账本残差
都严格低于 $10^{-12}$；非反向时混合路径必须与纯单元特征路径逐位相同；强度非负。

## 3. 流式块门

每次全局固定点迭代使用 block Jacobi：核心块内部和所有 halo 都读取同一次旧迭代，更新
只写回核心块。halo 必须由完整全局频率边界精确覆盖两次 Lorentz 查询，不能用一个人为
宽组替代邻接细组。

正式 9632 组单单元状态比较整体、256 核心组和 512 核心组三条路径。单次映射误差必须
严格低于 $10^{-12}$；收敛固定点的强度、体积平均共动谱和标量观测量分别使用
$5\times10^{-9}$ 门。每个新进程峰值必须低于 6144 MiB。

## 4. 权限边界

7B5v 只关闭算子等价性门。即使通过，也只授权下一步实际完整深度单块资源探针，不自动
授权全轨道、物质反馈、Phase 4 替换或 UVOT。
