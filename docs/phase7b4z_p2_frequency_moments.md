## 1. 本阶段只改变什么

物理频带、三个实际一步状态、S8 角求积、16 点组内物理求积、38496 组 P0 有限参考、
$10^{-3}$ 精度门和 4816 个频谱自由度上限全部沿用 Phase 7B4x。[A/V]

唯一核心变化是把每个频率组的 P1 重构提升为 P2：

$$
x=\frac{2(\nu-\nu_{\rm c})}{\Delta\nu},
\qquad
P_{2}(x)=\frac{3x^{2}-1}{2},
$$

$$
q_{\nu}(x)=\bar q+3m_{1}x+5m_{2}P_{2}(x),
$$

$$
\bar q=\frac{1}{\Delta\nu}\int q_{\nu}\,{\rm d}\nu,
\qquad
m_{k}=\frac{1}{\Delta\nu}\int q_{\nu}P_{k}(x)\,{\rm d}\nu.
$$

因此每个物理组保存三个自由度。候选 32、64、128、256 和 341 groups per decade 对应
153、303、604、1205 和 1604 个物理组，最高候选恰好使用 4812 个频谱自由度。[A]

本阶段没有改变 ZO 动力学、温度、H/He 布居、耗散、观察者几何或 Phase 4 连续谱。[V]

## 2. P2 数值闭合

### 2.1 全组非负性

P2 重构是闭区间 $x\in[-1,1]$ 上的二次函数。代码解析检查两个端点和区间内顶点；若最小
值为负，则只用一个共同因子 $\theta$ 缩放 $m_{1}$ 与 $m_{2}$，保持 $\bar q$ 不变：

$$
q_{\nu}^{\rm lim}(x)
=
\bar q+\theta\left[3m_{1}x+5m_{2}P_{2}(x)\right].
$$

Wien 尾可能进入 IEEE 次正规数范围。实现先用 $m_{1}/\bar q$ 和 $m_{2}/\bar q$ 求无量纲
最小值，再按实际浮点间距推导向可实现域内的最小舍入余量。这个处理不改变组平均，不设置
强度 floor，也没有使用 `clip` 或 `nan_to_num`。[A/V]

### 2.2 频率求积和碰撞乘积

三点 Gauss--Legendre 节点精确表示 P2，并用于三个独立正强度输运。P2 系数与 P2 角平均
强度的乘积最高为四次；投影该乘积的 $m_{2}$ 又多乘一个 $P_{2}$，最高为六次。因此散射源
投影使用四点 Gauss--Legendre 规则，而不是三点规则。[A/V]

### 2.3 Lorentz 搬移和 ALE

强度、发射率和消光仍分别遵守

$$
\frac{I_{\nu}}{\nu^{3}},
\qquad
\frac{\eta_{\nu}}{\nu^{2}},
\qquad
\chi_{\nu}\nu
$$

的不变量。每个源组与目标组交叠区间上精确积分二次密度的零阶、一次和二次原始矩，再转换
为目标组的 $\bar q$、$m_{1}$ 和 $m_{2}$。实验室系强度、移动控制体储能、ALE 面通量、
共动碰撞源和四维力仍在同一个后向 Euler 联立残差中计算。[A/V]

## 3. 独立算子控制

- P2 三节点投影精确回收制造二次 Legendre 谱；
- 解析二次谱的 Lorentz 搬移回收独立八点投影；
- 零速度时三个频率节点逐个回到三个独立定常 ALE 解；
- 频率常数刚体平移平衡误差为 $5.6557\times10^{-16}$；
- 对应联立残差为 $7.1261\times10^{-16}$，总能量账本残差为
  $7.1658\times10^{-17}$；
- 移动平衡中 limiter 触发数为 0；
- 次正规 Wien 尾的非负回归保持原组平均，没有 floor；
- 源文件中不存在禁用的 `nan_to_num` 或 `clip`。[V]

这些控制证明 P2 公式和独立 ALE 实现可以回收解析极限；它们不保证实际动态谱在有限自由度
内达到目标。[V/O]

## 5. 残差、limiter 和成本

![Phase 7B4z P2 operator diagnostics](../outputs/phase7b4z_p2_operator_diagnostics.png)

**左上。** 最冷表层 153 与 303 组的联立残差分别约为 $1.55\times10^{-6}$ 和
$8.17\times10^{-8}$，都高于 $2\times10^{-8}$。最大速度 604 组出现
$2.57\times10^{-4}$ 的非单调尖峰；同状态的 1205 与 1604 组又回到约
$1.79\times10^{-11}$。失败点没有删除。[V]

**右上。** 对应总能量账本在异常 604 组最大速度点达到 $5.57\times10^{-7}$；其余最高
候选的总账本约为 $9.88\times10^{-12}$--$1.29\times10^{-10}$。逐组相对账本在物理量
接近零的组可大于 1，所以正式全带判断使用频宽加权总账本，同时仍在 CSV 中保留逐组值。
[V]

**左下。** 最终 limiter 在实际状态中触发 228--1119 次；累计触发可达 47454 次。它主要
涉及 Wien 尾、系数阈值、Lorentz 交叠和固定点投影，随分辨率不单调。异常残差与大量
limiter 同时出现，说明 P2 可实现性投影是重要数值风险；但不能仅凭相关性断言它完全造成
H I 率误差。[V/O]

**右下。** 一单元最高候选耗时约为 $9.7$--$23.9\ {\mathrm{s}}$。该成本尚未乘以 N128、正式
角阶、辐射子网格和 2048 相位，因此失败后没有继续增加 P2 组数。[V/O]

## 6. 与 P1 的同预算比较

| 表示 | 物理组数 | 频谱自由度 | 最大速度误差 | 最大宽度变化误差 |
|---|---:|---:|---:|---:|
| 普通对数 P1 | 2408 | 4816 | $9.0435\times10^{-4}$ | $2.4547\times10^{-3}$ |
| 普通对数 P2 | 1604 | 4812 | $7.5063\times10^{-4}$ | $2.5472\times10^{-3}$ |

P2 改善了最大速度状态，却没有改善决定性的最大宽度变化状态。也就是说，第二个组内矩不是
“普遍更准”的生产选择；在固定总自由度下，它同时减少了控制体数量，而 H I 阈值附近的
动态积分仍需要更合适的坐标或局域表示。[V/O]

## 7. 正式判定

| 判据 | 结果 |
|---|---|
| P2 解析投影与 Lorentz 搬移 | 通过 |
| 零速度与移动平衡 | 通过 |
| 全部候选算子门 | 失败 |
| 三实际状态 $10^{-3}$ 频率门 | 失败 |
| 4816 自由度效率门 | 失败，因为没有精度通过点 |
| P2 生产组件门 | **失败** |

因此不选择 P2 生产网格，不授权 S16/S24、16/32 辐射子网格、时间扫描、2048 相位动态
全轨道、物质温度/布居反馈、Phase 4 替换或 UVOT。[A-classification/V]

下一种表示不能只是把多项式阶数继续提高。当前证据更支持单独测试以
$y=\ln\nu$ 为守恒坐标、并对 H I 光致电离积分量具有显式误差控制的表示；它仍须重新声明
守恒变量、Lorentz 平移、正性、自由度预算和同一三状态门。这个建议属于下一阶段工作假设，
不是已经验证的解。[A/O]

后续 Phase 7B5a 已完成前半项：真正的 $y=\ln\nu$ 守恒 P1 在 4816 自由度下仍得到
$2.4569\times10^{-3}$ 的最大宽度变化/H I 率误差，与普通 P1 实质相同。因此当前开放项
进一步收窄为“显式控制目标率泛函，同时保留总能量守恒”，而不是再次只更换坐标。[V/O]
