## 1. 联合测试的边界

本阶段只回答：物理阈值对齐和组内一次矩是否具有互补收益。物理频带仍为
$0.1$--$5000\ {\rm eV}$，角度仍为 S8，物质温度和 H/He 布居仍取规定的一步状态，
有限参考仍为 38496 组普通对数 P0。[A/V]

候选阈值网格使用 16、32、64、128 和 256 个变换 decade 面板，对应 143、285、568、
1134 和 2265 个物理组。每组保存 $\bar q$ 和 $m$，因此最高候选有 4530 个频谱自由度，
低于预声明的 4816 自由度上限。[A-classification]

没有在看见失败后加入 512 面板候选；那会超过本阶段预算，而且无法回答“预算内是否通过”。

## 2. 独立控制

全部候选满足：[V]

- H I、He I、He II 离化阈值是精确控制体边界；
- 组宽严格为正；
- 组平均乘组宽与同节点 Planck 积分恒等；
- 两层不规则 Lorentz 守护组覆盖一次碰撞往返；
- 没有 `nan_to_num`、`clip`、任意 floor 或事后重归一化。

568 组阈值局域 P1 的移动频率常数平衡误差为 $1.0633\times10^{-14}$，联立残差为
$1.3121\times10^{-15}$，总能量账本残差为 $7.7645\times10^{-17}$；因此不规则边界
与 P1 搬移本身没有破坏运动学平衡。[V]

## 4. 为什么不能称为改进

在相近成本上比较决定性压力点：[V]

| 表示 | 物理组数 | 频谱自由度 | 最大宽度变化误差 |
|---|---:|---:|---:|
| 普通对数 P1 | 2408 | 4816 | $2.4547\times10^{-3}$ |
| 阈值局域 P1 | 2265 | 4530 | $3.4545\times10^{-3}$ |

阈值局域 P1 对最低组数和部分静态量有帮助，但没有降低决定性的动态 H I 误差。Phase 7B4w
已显示阈值聚点无法修复 P0 的组内斜率缺失；Phase 7B4y 进一步显示，一次矩与该聚点方式
也不是简单相加就能获得预算内闭合。[V]

## 5. 阶段判定与下一边界

| 判据 | 结果 |
|---|---|
| 阈值网格几何 | 通过 |
| 阈值局域 P1 移动平衡 | 通过 |
| 全部候选残差、账本和非负性 | 通过 |
| 三状态 $10^{-3}$ 频率门 | 失败 |
| 2408 组、4816 自由度效率门 | 失败 |
| 阈值局域 P1 生产组件门 | **失败** |

因此不授权 S16/S24、16/32 辐射子网格、时间步扫描、2048 相位全轨道、物质反馈、Phase 4
替换或 UVOT。后续 [[eccentric_tde_observer/docs/phase7b4z_p2_frequency_moments|Phase 7B4z]]
已单独测试普通对数 P2；它改善最大速度点，却仍失败最大宽度变化/H I 率与全部候选算子门。
下一候选因此转向对数频率坐标中的守恒表示。[A/V/O]
