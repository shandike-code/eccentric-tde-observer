## 为什么必须重算辐射场

7B8a 的廉价残差沿用了当前辐射场。物质温度和布居改变后，连续吸收、Milne 发射和
Lorentz--ALE 碰撞源都会改变；只有重新完成全部 9632 频群、32 方向和 4096 辐射深度的
映射，才能评价真实耦合方向。`[V]`

## 决策

映射、频率所有权、非负性和资源门通过，因此只授权 Phase 7B8c 的全局拼接源项与真残差
诊断。它本身既不是辐射固定点，也不是物质--辐射耦合固定点。`[A-preregistered/V/O]`
