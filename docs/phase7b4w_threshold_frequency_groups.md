## 1. 本阶段只问什么

Phase 7B4v 已证明完整 Lorentz 碰撞源与 ALE 储能、移动界面通量可以在同一残差中闭合，
但普通对数 P0 网格在最大宽度变化状态上需要约两万个物理组才能相对有限参考达到
$10^{-3}$。Phase 7B4w 不改 ZO 动力学、不改物质状态，也不实现 P1；它先检验一个更小的
问题：把频率组集中在 H/He 离化阈值附近，能否在显著少于两万组时保留动态原子率。[V/O]

本阶段预声明两道相互独立的门：[A-classification]

1. **频率精度门**：三个真实一步状态的全部监视量相对 38496 组有限参考均小于
   $10^{-3}$；
2. **效率门**：首次通过精度门的物理频率组数不超过 4814。该上限对应 Phase 7B4v
   已测试的普通对数 1024 组/decade 档位，而不是看完结果后选择的阈值。

只有两门和算子控制同时通过，阈值局域 P0 才能成为下一层组件候选。

## 2. 阈值局域有限体积网格

物理频带固定为 $0.1$--$5000\ {\rm eV}$，并在 Verner H/He 数据中的 H I、He I、He II
基态离化阈值处精确分段。对每个分段 $[E_{k},E_{k+1}]$ 定义超阈值坐标

$$
u=\log_{10}\left[1+\frac{E-E_{k}}{E_{\rm s}}\right],
$$

其中

$$
E_{\rm s}=k_{\rm B}(5000\ {\rm K})=0.4308666631\ {\rm eV}.
$$

在 $u$ 上等距分面，再映回能量边界

$$
E=E_{k}+E_{\rm s}\left(10^{u}-1\right).
$$

这样每个阈值右侧自动获得最细分辨率，离阈值越远组宽越大。阈值是有限体积控制体边界，
不是只供组内积分使用的求积节点。代码在浮点映射后重新写入原子数据表中的精确阈值；若
边界不再严格递增则直接失败，不裁剪或合并频率组。[A/V]

任意不规则物理边界还需能够承受一次实验室系到共动系碰撞查询和一次返回实验室系的
Lorentz 搬移。新接口保留全部物理边界，并分别加入一层共动碰撞守护组和第二层外部
实验室守护组。守护组只扩展 Doppler 查询定义域，不进入正式频带积分。[A/V]

2. `maximum cell speed`：单元速度绝对值最大；

## 5. 与普通对数 P0 的比较

最大宽度变化状态是决定性压力点：[V]

| 表示 | 物理组数 | 最大误差 |
|---|---:|---:|
| 普通对数 P0 | 4814 | $3.3462\times10^{-3}$ |
| 阈值局域 P0 | 4527 | $3.3326\times10^{-3}$ |
| 普通对数 P0 | 9625 | $1.4374\times10^{-3}$ |
| 阈值局域 P0 | 9053 | $1.5876\times10^{-3}$ |
| 普通对数 P0 | 19249 | $5.3179\times10^{-4}$ |
| 阈值局域 P0 | 18105 | $5.7070\times10^{-4}$ |

在相近组数下，两种 P0 表示的最坏误差几乎相同。阈值局域网格明显改善静态冷表层和部分
低组数原子率，但无法用不超过 4814 组关闭动态最大宽度变化门。物理对齐网格有效，却没有
解决 P0 只保存组平均强度、丢失组内斜率的核心成本问题。[V/O]

## 6. 阶段判定

| 判据 | 结果 |
|---|---|
| 阈值几何、正组宽和精确离化边 | 通过 |
| 不规则网格移动热平衡 | 通过 |
| 联立残差、能量账本和非负强度 | 通过 |
| 三个真实状态相对有限参考的 $10^{-3}$ 门 | 通过，首次在 18105 组 |
| 不超过 4814 组的效率门 | **失败** |
| 阈值局域 P0 生产组件门 | **失败** |
| 正式生产频率组数 | 未选择 |

因此：[A-classification/V/O]

- 下一小阶段需要守恒 P1/频率矩表示；
- 不授权 S16/S24、16/32 辐射子网格和时间步联合门；
- 不授权 2048 相位全频动态轨道；
- 不反馈温度或 H/He 布居；
- 不替换 Phase 4，不进入 UVOT；
- 不把 38496 组有限参考称为连续真值。
