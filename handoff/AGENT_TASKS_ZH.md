# 给学校端 agent：研究目标、现状与执行顺序

## 用户要完成的事情

把椭圆 TDE 盘观察者光谱中的局域 blackbody/modified-blackbody，升级为有物理依据、通过数值验证的
H/He 大气连续谱。用户允许研究适当放宽内部辐射残差条件，并希望你主要负责起跑、监督、排障和判断结果。
仓库已提供从初始化到一个物质试探步判定的 batch 流水线；不要重新发明已有率核和转移核。

先读根目录 `AGENTS.md`、`hpc/README.md`。配置本仓库 Git 身份后再改代码。真实计算用 Slurm；
这不是 GPU 模型训练，不需要 HF 下载。不要使用 WebShell 的整机资源数替代 Slurm allocation。

## 冻结的科学状态

- corrected ZO 2022 Erratum 源面积、盘几何、投影/自遮挡、频移和观察者系变换已有实现与验证。
- 正式整盘连续谱仍是 blackbody/modified-blackbody；尚未被生产大气表替换。
- H/He 模型包含基态连续过程、碰撞电离/三体逆率、Milne 和自由—自由发射、相干电子散射。
- 周期物质参考在局域 Planck/Rosseland 闭合下做到 128 深度、2048 相位；这不是全轨道非局域 NLTE。
- 当前实际非局域全柱为 9632 频率组、32 方向、4096 辐射深度、76 自然频率块；只覆盖一个代表环带、一个物理时间步。
- 先前 `0.125` 物质候选确实完成了两个严格收敛辐射态和稳定正式反馈，随后物质响应离开正气体热能物理域。
  它被拒绝，不代表所有静态解不存在。
- 后来的 `0.0625` 候选停在 7B9du 第 8 次追加映射。最新残差约 `2.1041349752e-4`，
  边界谱变化 `4.4009808e-6`、总通量变化 `2.8377981e-6`；严格 `1e-4` 门未过，且该端点未完成正式反馈对。
- Phase 6 只有条件性运动学线核。没有真实 Halpha/Hbeta/He II 绝对光度、激发态 bound-bound NLTE、
  金属线遮蔽或完整 Compton 重分布。

证据：`handoff/evidence/` 是 Git 内小型快照；完整报告路径在各 JSON 中。新计算不能改写这些历史判决。
配置里的部分 `phase_index` 是阶段编号；真正物理相位需由物质 NPZ 的 `phase_index` 和 native
`_context` 的 `phase/following` 核对，不能将不同阶段编号误作不同轨道相位。

## 阶段 A：先完成运行条件与迁移验证

1. 记录 Git commit、Python/NumPy/SciPy/BLAS、机器架构、Slurm job ID、分区/QOS、实际 CPU 和内存。
2. 恢复 runtime 输入包并校验 SHA。Git 本身不含辐射态；默认用 cold 初始化，或转入 warm seed。
3. 提交 `hpc/submit.sh smoke`，再提交 `hpc/submit.sh block-check`。通过后运行一个完整映射的 benchmark。
4. 核对 native 正值路径、原子率/守恒控制，以及 Mac 到 Linux 的差异。哈希证明源文件相同；
   不要求所有跨 CPU 浮点结果逐位相同，但任何放宽比较误差都要说明来源和规模。
5. 测量每个 worker 峰值 RSS、总 RSS/Slurm MaxRSS、块耗时、完整映射墙钟和磁盘 I/O。
   默认 2 worker；资源获准后用独立目录比较 4/8 worker。不要一上来用 48 worker。
6. 做一次受控 batch 边界续跑，确认已完成块不会重复计数、半态不会被接受、SHA 能捕捉篡改。

交付：`outputs/hpc/<run>/` 下的环境 JSON、state/config、完整 map 历史、日志和资源比较表。
只有这一阶段完成，才能把学校端完整运行当作验证过的执行路径。

## 阶段 B：默认自动流程——当前候选的辐射与反馈判定

按 `hpc/README.md` 执行 prepare、一次 map、随后有限批次或 `hpc/supervise.py`。
默认候选门槛为 `2.5e-4`，不是改写历史 `1e-4` 的合格线。

自动处理内容：

- cold 或 warm 数值初值；三个工作态保留连续两个已审计输入及后继态；
- 全频分块源映射、输入/块 SHA 检查、可恢复提交和总迭代预算；
- 两个连续输入态都满足内层残差、边界谱和 bolometric 变化门后停止辐射迭代；
- 两态的正式 H/He 光致电离、复合、净加热与逆四力一致性检查；
- 同一冻结物理旧时间层下的物质响应、正气体热能/温度/布居、内层噪声与三个残差收缩比；
- 输出 `one_material_trial_accepted` 或 `material_trial_not_accepted`。

这一步不需要你临时写原子物理或转移代码。看到失败先解释具体 gate，不要只看终端是否退出 0。
监督器遇到程序错误、OOM、超时或未知作业状态停止；修复或确认恢复条件后再提交。
若某个 gate 接近阈值，保留它而不圆整成通过。

## 阶段 C：放宽门槛到底是否可信

在相同物质候选、频率/角度/深度、物理步长与源定义下，分别建 `2.5e-4`、`2e-4`、`1e-4` 的独立运行。
优先用同一 warm seed；无 warm seed 时记录相同 cold 初始化。

除内部残差外，比较：

- 表面谱形/总能流及固定诊断带；
- H I、He I、He II 光致电离率和总复合率；
- 原子加热、直接共动加热、逆四力加热；
- 物质响应的温度、布居、目标能量与三个残差范数；
- 内层噪声/物质试步信号是否仍低于原有 `0.1` 门。

若放宽后这些反馈或物质判定变化显著，不接受放宽，只记录它为何不能节省总成本。
表面谱相邻变化很小不等于各频点、各深度或物理预言的误差同样小。

## 阶段 D：耦合柱——这部分仍需要依据 B/C 的实际结果推进

自动流程当前有意停止在**一个有限物质试探的判定**。后面的外层迭代不能在尚无结果时假定必收敛。

- 若当前步被接受：它最多接受一个非线性物质步。复用 `coupled_material_iteration.py`、
  `coupled_material_acceleration.py`、`material_trust_region.py`、`coupled_material_line_search.py`
  和 `formal_feedback_pair.py`，在新阶段目录推进外层并持续更新真实反馈。
- 若物理域失败：沿已声明方向做有界回溯或检查该响应闭合；不能通过裁剪、floor 或改物理步长蒙混过关。
- 若内层噪声主导：先改善内层精度或有限试步信号，不能把差分噪声当 Jacobian。
- 若残差只在某范数下降：同时保留质量加权、L2 和最差单元，不选最好看的指标宣布收敛。
- 记录真正的外层固定点残差及趋势，完成两层精度、能量闭合与分辨率敏感性。

不要直接启动 2048 相位乘所有环带的暴力扫描。先关闭代表柱的耦合问题，否则只是复制同一个未解决瓶颈。
这一阶段如需代码补充，尽量扩展已有受控模块；用户已委托合理实现和 batch 验证，无需逐微阶段重新询问。
但不要把初版 HPC driver 宣称为已实现任意物质候选、全外层自动 Newton、全周期或全盘扫描器。

## 阶段 E：完整局域强度与观察者接入

代表柱通过后，按 `docs/phase7_post_convergence_branch_contract.md` 的依赖顺序扩展。
覆盖候选源的径向/轨道相位定义域，检查准静态时间尺度、热时间、历史依赖、角度/频率/深度收敛。
静态有效性证据不足时状态仍为 `not_ready`；单个算法失败不是静态近似失败的证明。

如果静态描述有效，生成带单位、有效域、输入哈希和角分辨强度的有限表，接入
`annulus_bridge.py:AngleResolvedAnnulusTable`。如果需要动态历史，生成携带相位/历史的强度提供器。
然后实现 Phase 4 local-intensity adapter，重跑 `scripts/phase4_final_atlas.py` 和
`scripts/phase5a_observer_frame_flambda.py`。

必须展示相同源几何下 blackbody、modified-blackbody 与 H/He 连续谱的差异，分别报告
bolometric、谱形、诊断带、ionizing photon rate、峰频和角分布。UVOT 仪器层在局域闭合之后。
真实谱线形成属于另一微物理阶段，不把归一化线核冒充 H/He 大气线谱。

## 完成标准与汇报格式

最终“局域大气升级完成”至少需要：收敛耦合柱、完整定义域的合格强度、能量/网格/历史审计、
可重跑观察者适配，以及清楚写明缺失微物理。仅 B 阶段通过不能标记整个项目完成。

每个 batch 或里程碑汇报以下内容即可：

1. Git commit、run ID、Slurm job ID 与实际资源；
2. 完成/待完成块和迭代，是否有 active partial state；
3. 辐射残差、边界量、H/He 率/加热、物质残差及失败门；
4. 实测墙钟/RSS/数据量，下一批预计成本；
5. 本轮究竟证明了什么，没证明什么，下一条可执行命令。

失败时保留配置、输入与失败报告。只保留必要的大态，清理既有历史态要取得用户批准。
新代码、任务说明和小型审计报告提交 Git；计算输出和大态留在平台存储，并提供路径与哈希。
