# 共同频域反馈后的固定物质精度追加 v1

作业75943已在新频域协议下结算旧保留两态的反馈：全部态门通过、两响应正气体热能、三范数收缩，但三个加热稳定门和噪声门失败。本实验保持同一个1/64物质候选，改善内层辐射精度，不重选方向、不缩短物理步长、不接受新物质步。

在独立`common-precision-maps-20260923`目录建立新工作态。源为`step16-backtrack-20260923/full`最后已提交map的输出，只作数值初值；源trial必须与桥输入逐位相等，encoded/base/direction/residual/alpha及native解码身份完整核验。源run仍有旧协议下的pending失败反馈，该标记保持原样，不在旧run续跑。新分支的前提是共同频域桥已完成且Mac复核通过，而不是忽略旧反馈。

预算为32CPU、128GiB、16worker、2小时。最多8张新map：先4张；第4张后，只有残差较第1张下降、最后两张均满足原辐射1e-4、边界谱和总通量1e-3且所有值有限、worker内存严格低于6GiB，才自动再跑4张。这只是追加预算的理由，不证明加热或物质残差已收敛。首次或第二阶段完成后保留端点；不自动续交、异常即停。

在第4和第8张后，将该阶段最后两张map的输入分别复制为previous/final独立检查点，并保存最后的映射输出。每次复制前后核SHA和大小，保存原history行与新路径清单，再做小工件快照。不是指向循环槽的硬链接；后续工作不会覆盖已保留两态。启动前至少预留12份状态文件空间。所有旧输入、协议、失败判决只读。

采用原`pipeline.batches/aggregate`与诊断单map实现。每个worker的原生6GiB及独立`/proc`6GiB守卫、hugepage关闭、批次边界USR1停止保持；中断保留部分map和状态。此独立驱动暂不提供原地恢复命令，恢复前须读取部分态并声明恢复方案，不盲重交。

本批次故意只产出可重求反馈的固定态，不调用旧频域formal适配器，也不会输出物质接受判决。下一步必须对保存的两对端点用独立版本的共同频域完整反馈路径重算原子率、原子加热及lab四力，再评估原16门。若通过，还需新基态四组合比较、信赖域和同态双确认。已接受计数保持15；代表柱收敛和全盘强度表都未完成。
