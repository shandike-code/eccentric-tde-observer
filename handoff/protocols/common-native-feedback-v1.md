# 新端点的共同频域完整反馈 v1

本入口用于`common-precision-maps-20260923`第4和8张之后保存的两对固定物质辐射端点。先进行已知端点block24的端到端预检，随后32CPU/128GiB、16worker依次求4个完整反馈态，最多304个新反馈worker；不计算新辐射map、不推进物质或物理时间。

## 计算路径和身份

`common_native_feedback.py`提供与原适配器一致的worker参数接口。每个worker首先调用未修改的`run_worker_adapter`，在独立`.legacy.npz/.legacy.json`保存全部原生原子率、吸收/发射功率、原子加热和旧三种源。然后从同一冻结辐射场和物质态重新取得核心/halo、共动均强度、消光和发射系数，调用已验证的`common_frequency_four_force`。共同共动窗口在每条lab射线上的积分域为$[A/D,B/D]$；先独立求lab能量/动量矩，再逆变换物质加热。不能从原子加热或已测差值生成新formal。

新partial只改变`source_formal_heating_erg_s_cm3`字段，其他字段必须与本次原生计算逐位相等；旧formal保留在legacy文件。common文件另外保存两矩、加热和绝对碰撞源尺度。原父进程按76块汇总、4096→256×16→128深度映射，检查原拥有权、非负率/强度、有限、镜像、direct/common守恒、内存及900秒实际态墙钟门，再调用原物质响应及16个接受门。

新协议的`adapter_runner`明确指向新入口，旧适配器另作冻结依赖。删除旧bridge的复用manifest开关、旧origin和旧反馈artifact来源；不能通过已完成旧manifest跳过新计算。保留trial/base/方向/旧时间层的原SHA和数值身份，每对协议只指向独立保存的新dat。两端点输入SHA及连续history必须匹配，原子率和加热必须针对新dat实际重求。物质响应仍由atomic heating驱动，四力只用于源一致性核验。

当前固定候选为1/64；每对运行前精确检查encoded/base/residual/direction/alpha、decode、native镜像温度/H/He/rho和phase/dt。相位1367、dt889.419892762322秒及旧层不变。本入口仅通用到可指定新辐射端点；它的外层研究调度仍明确限定本候选，不假称已有任意物质自动求解器。

## 来源和资源

冻结全部当前src/scripts/hpc/operations/diagnostics Python文件及新sbatch/测试/本协议。父进程前后核代码、实际小输入和本对dat的SHA；worker核直接入口/算子/包装层和原模板依赖。已经完成的mapping计算以终态、保留manifest、history和当前trial身份为依据，验证实际读取的4个端点，不重新读取整个历史祖先配置中的301GiB数值初值。历史声明没有删除或改写；旧输入的前后核验仍由75951负责，只有它完成并COMPLETED才启动完整反馈。

pilot默认4CPU/16GiB、单worker、30分钟，在历史已审final block24实际重求完整原生输出和共同域四力；所有原生字段须与原反馈块逐位相等，新四力全部字段须与75908独立计算逐位相等。对照是端到端接口验证，不作为新端点的物理证据。只有pilot通过才启完整32核作业，预算2小时。

每worker经stdlib relay观测/proc；原生峰值和独立观测均严格小于6GiB，hugepage关闭，BLAS单线程。父进程沿用已验证的批次停止守卫，USR1后已派发批次提交再停，不派发下一批。代码、源哈希、资源或态门故障立即终止。物质响应离开正气体热能域则保存失败和账本后停止后续端点对。单纯pair精度或收缩门未过时，允许继续评估已经保留的map8对；不产生新map，不放宽门。

状态门用本作业实际累计worker批次墙钟（不是复用桥的历史成本上界），上限900秒；原HPC历史7200秒配置不继承。无自动重交/覆盖，部分工件保留，恢复须另审；本版本不提供原地续跑命令。

## 结果和接受边界

每对计算后再核全部新partial与legacy/common关系、所有独立资源回执和完整态门。响应成功时保存完整残差和温度/H/He、逐层能量账本，复核目标总能量和布居，再计算三范数；物理异常保留原错误，不伪造未评估指标。

即使某对16门全部通过，本作业`material_step_promoted`仍为false，已接受计数仍15。须在同一新频域协议下完成新基态对照、四个端点组合的残差收缩、信赖域和同态双确认，再决定是否接受第16步。频域截断、单柱耦合收敛、径向/轨道覆盖、全盘$I_{\nu}$仍是后续验证，不能因算子一致而宣布完成。
