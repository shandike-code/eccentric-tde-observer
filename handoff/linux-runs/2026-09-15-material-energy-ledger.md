# 物质响应能量账本与反馈敏感性诊断

针对 `outputs/hpc/hhe-r025-warm` 的两个反馈端点，回答两个问题：

1. 物质响应为什么离开正气体热能物理域——**逐层能量账本**（§2）；
2. 加热稳定性指标 6.63× 超阈由什么构成——**指标分解**（§3）。

工具：`diagnostics/material_energy_ledger.py`（只读，不写入 run 目录）。
测试：`tests/test_material_energy_ledger.py`（4 项，全通过）。
本文件**不重启任何计算**，全部结论来自既有工件。

## 1. 失败的物理机制

原响应在 `ground_state_material_temperature_from_specific_energy_k` 里做：

```
thermal = energy − ionization(H_new, He_new)
if any(thermal <= 0): raise PhysicalDomainError("...no positive gas heat")
```

其中 `energy = u_old + dt·Q/ρ`，`u_old` 取自**旧时间层**。

## 2. 逐层能量账本

`phase_index = 1367`，`dt = 889.419892762322 s`，128 个物质层。

| | previous 端点 | final 端点 |
|---|---|---|
| 失败层数 | **16 / 128** | **14 / 128** |
| 失败层质量占比 | **0.16354** | **0.13424** |
| 最小剩余气体热能 | **−5.736870e+12 erg/g** | **−5.353602e+12 erg/g** |
| 最大缺口（相对旧气体热能） | **0.52547** | **0.49036** |
| 最严重层 | cell 96（质量占比 0.011895） | cell 96（同） |

失败层索引（previous）：`62,63,64,65,73,74,75,85,86,95,96,97,104,105,106,107`

### 最严重层（cell 96）完整账本 —— previous 端点

| 量 | 值 |
|---|---|
| 旧气体热能 `u_gas_old` | 1.091763e+13 erg/g |
| 旧电离能 `u_ion_old` | 1.441531e+13 erg/g |
| 旧物质总能量 `u_old` | 2.533294e+13 erg/g |
| 新电离能 `u_ion(new)` | 1.441531e+13 erg/g |
| **Δ电离能** | **−1.142771e+03 erg/g**（相对 7.9e-11） |
| `Q`（原子率加热） | **−8.041071e-01 erg/s/cm³**（负 = 净冷却） |
| **`dt·Q/ρ`** | **−1.665450e+13 erg/g** |
| 目标物质总能量 `u_old + dt·Q/ρ` | 8.678440e+12 erg/g |
| **剩余气体热能** | **−5.736870e+12 erg/g** |

**读法：** `dt·Q/ρ` 的绝对值（1.6655e13）是**旧气体热能（1.0918e13）的 1.53 倍**。
目标总能量（8.678e12）已经**低于新电离能（1.4415e13）**，所以剩余气体热能为负。
**Δ电离能可以忽略**（1.14e3 对 1.44e13）——失败由**辐射冷却项**主导，与电离能变化无关。

### 两个端点的差（仅观测敏感性，**不是严格误差界**）

| 量 | 值 |
|---|---|
| 最小剩余热能变化 | **+3.832687e+11 erg/g**（−5.7369e12 → −5.3536e12，改善约 6.7%） |
| 失败层数 | 16 → 14 |
| max&#124;Δ电离能&#124; | **47.29 erg/g** |
| max&#124;Δ(`dt·Q/ρ`)&#124; | **5.024090e+11 erg/g** |
| max&#124;ΔQ&#124; | 0.027519 erg/s/cm³ |

两端点差的量级几乎全部落在辐射项上（5.0e11），电离能项贡献 47（相差 10 个数量级）。
**这只是相邻两个端点的已观测敏感性，不能当作误差界或收敛速率使用。**

## 3. 加热稳定性指标由什么构成

五个正式指标的分子/分母（本工具复现值与原报告逐一相同）：

| 指标 | 分子 | 分母 | 比值 | 门 |
|---|---|---|---|---|
| `photoionization` | 2.0411e+17 | 2.6319e+21 | 1.9243e-04 | 1e-3 ✅ |
| `total_recombination` | 1.4957e-06 | 8.4448e+00 | 1.7712e-07 | 1e-3 ✅ |
| `atomic_rate_heating` | 3.8015e+11 | 5.7324e+13 | **6.631653e-03** | 1e-3 ❌ |
| `source_direct_heating` | 3.8015e+11 | 5.7324e+13 | **6.631653e-03** | 1e-3 ❌ |
| `source_formal_heating` | 3.8015e+11 | 5.7324e+13 | **6.631676e-03** | 1e-3 ❌ |

`atomic` 与 `direct` 数值相同；三者的分母都是 5.7324e13，即**同一组净加热量**。

### 深部分布：**不集中在少数层**

| 量 | 值 |
|---|---|
| 贡献 50% 分子的深度数 | **591 / 4096** |
| 贡献 90% | 1334 / 4096 |
| 贡献 99% | 2522 / 4096 |
| **单个最深度的最大占比** | **9.33e-04**（不到千分之一） |
| 分子占比最高的 5 个物质层 | 60, 67, 71, 56, 68（合计 14.19%） |

**分子散布在全部 4096 个深度上，没有任何单一深度或少数层主导。**

**物质层 96（账本里最严重的失败层）只占分子的 0.109%。**
即：**加热不稳定与物理域失败在空间上并不重合。**

### 净加热是大项相减的小差值

| 量 | 值 |
|---|---|
| `absorbed − emitted − net` 闭合误差 | 8.32e-14 相对 |
| `|net|/(|ab|+|em|)` 中位 | **1.6428e-03** |
| 同 p90 / 最大 | 1.9896e-02 / 2.3697e-01 |
| **中位放大因子** | **608.7** |

**是的——局部净加热是两个几乎相等的大量的差：中位只有毛额（吸收+发射）的 0.16%。**

### 分量变化 vs 净量变化

| 量（4096 深度） | 相邻端点 max 相对变化 |
|---|---|
| `absorbed_power` | **1.9478e-05** |
| `emitted_power` | **0.0000e+00**（逐位不变） |
| `atomic_rate_heating`（净） | **2.2500e-03** |

`emitted_power` 逐位不变是**预期**的：发射由冻结物质态决定，两端点用的是同一个旧时间层。
变化只来自依赖辐射场的吸收项。

**结论（区分「超阈」与「发散」）：**
吸收项只变了 **1.95e-05** 的相对量，×608.7 的相消放大 ≈ **1.19e-02**，与观测到的
6.63e-03 同量级。所以 **6.63e-3 是"稳定的分量经大项相消放大"的结果，不是数值发散**；
三个加热数组全程有限，`Q` 取值域 [−8.99, +12.25] erg/s/cm³，无 NaN/Inf。

### `Q` 的符号结构

- 4096 深度：**40.72% 为负**（净冷却）
- 128 半胞：**40/128 为负**，索引 `60-66, 71-77, 83-88, 94-99, 104-108, 113-116, 121-125`
- **账本里的失败层是这些负 `Q` 层的子集**：`62-65 ⊂ 60-66`、`73-75 ⊂ 71-77`、
  `85-86 ⊂ 83-88`、`95-97 ⊂ 94-99`、`104-107 ⊂ 104-108`

## 4. 本轮**确立**与**未确立**

**确立：**

1. 失败机制：深层净冷却，`dt·Q/ρ` 超过旧气体热能的 1.53 倍，目标总能量跌破新电离能。
2. Δ电离能可忽略（相对 7.9e-11），失败与电离能变化无关。
3. 账本口径与能量记账**自洽**：拆分逐位复现原函数（差 0.0），守恒残差 ~2e-16。
4. 加热指标超阈来自**大项相消放大**，不是发散；分量本身稳定到 2e-5。
5. 加热分子散布在全部 4096 深度，与失败层在空间上不重合。

**未确立（不得当作结论）：**

1. **两类未满足条件是否同源——未确立。** 物理域失败在深层局部（16 层），加热指标是全场分布
   （591 个深度占一半分子），两者不重合；但这**不足以**判定二者无关，因果仍待诊断。
2. **是否主导内层噪声——未确立。** `inner_noise_to_trial_signal_l2_ratio_below = 0.1` 因异常
   **从未被求值**，`encoded_residual` 的噪声/信号比保持未评估，**本报告不提供替代值**。
3. **是否存在实现错误——未发现，但不等于不存在。** 单位、时间、密度、索引、输入哈希、
   能量记账均未发现错误；这只说明在已检查项上自洽。
4. **静态近似是否有效——未触及。** 判定文件自身 `static_approximation_rejected_from_one_failed_trial = False`。
