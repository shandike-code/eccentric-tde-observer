## 3. 必须撤回的推断

1. **旧方向的来源。** `phase7b9g_jv_fidelity_decision.py` 用低秩割线逆预条件器作用于基态残差生成方向；其 `strict_full_frequency_jv_evaluated` 为 False。相对差分步长 1e-7 的信号预算不足是当时的诊断，不能改写为“已经计算了受污染 Jv 并由此生成方向”。
2. **有限差分区间。** 旧设计中 h 约 3e-3—1e-2 依赖 `a15625-cont48`、`a078125-cont48` 的 signal/alpha；这两个运行已确认实际使用 0.0625 候选并撤回。没有有效候选身份的数据不能约束新 Jv 步长。
3. **1e-14 不是辐射内层误差。** `response_noise_floor.py` 的迭代次数、单 ULP 加热和局部核比较测的是算术敏感性；它不测完整辐射不动点误差。新方程残差与旧 encoded 残差的比值也不能当同尺度信噪比。独立复算的历史基态相邻方程残差 L2 差为 0.1322106620；这仍只是相邻漂移，不是真误差上界。
4. **有限差分工具尚不能认证方向。** `finite_difference_linearity.py` 依赖 config alpha、可能读取为空的 encoded 残差路径，比较长度而非完整向量，并遗漏基态内层误差。等长反向向量也能骗过长度检查。新增向量比较测试展示这一反例；旧工具不用于新科学判决。
5. **成本外推。** 最近收缩比约 0.992，不支持保证再跑 8—12 张就过门。三条链 24 张后仍没过门，停止自动延长。
6. **资源门与科学门分开。** 当前 `pipeline.feedback_protocol` 明确声明每个反馈态 7200 s 资源门。旧文字中的 900 s 不能无条件套用到所有新协议；以每个实际协议为准，不能以资源门更改推定科学门也已放宽。

## 4. 为什么先做零位移对照

定义物质向量为 x，固定物质的辐射映射为 M，反馈评估为 F。小步实验本应比较同一问题的 F(x+alpha*d, I) 与 F(x, I_base)。现在历史基态的 128 个响应单元全部物理可行，最小目标/旧气体热能为 1.010803；有限小步却产生严重负值。这可以来自真实响应变化，也可能包含两侧辐射精度或评估路径差异，尚未区分。

零位移实验固定 x=x_base，并从历史最终辐射 I_base 出发。计算两次映射，反馈分别消费 I_base 和 M(I_base)。第二次映射提供后一个反馈输入的算子残差；不会将 map2 输出误称为这里的 final 反馈输入。

- 第一反馈与历史同一辐射态的反馈比较：检验当前 Linux 解码/迁移/执行路径能否复现基态。
- 第二反馈与第一反馈比较：检验物质完全不变时继续内层迭代造成的反馈漂移。
- 若第一项不一致，先按单位、物质解码、频率/深度映射和输入来源定位差异，不建立新 Jv。
- 若第一项一致但继续映射漂移明显，先建立共同基态和候选的内层误差诊断。
- 若两项均稳定，才在明确共同尺度与误差预算下设计新的有限差分/方向实验。两张 map 本身不提供完整内层误差上界。

脚本 `operations/baseline_zero_control.py` 使用原步长和旧物理时间层、原方向元数据，唯一位移是 alpha=0；初始化前持久化并重读验证 trial。它只调用正式状态反馈评估，不调用物质步接受函数。最多 2 map、2 worker、默认 4 CPU/16G、墙钟 3.5 h，不自动重交；结束始终标记 `accepted_material_step=False`。异常保留目录，禁止盲目重跑覆盖。

## 5. 物理直觉与最终交付边界

在每个物质单元，旧总比能加本时间步的净辐射增量，是可分配给新气体热能及新电离能的总预算。净体积加热 Q 的单位为 erg cm^-3 s^-1，密度 rho 为 g cm^-3，步长 dt 为 s，所以 dt*Q/rho 的单位为 erg/g。先求新布居及其电离能，再从总预算扣除，得到目标气体热能。非正目标不能通过温度 floor 修复：floor 相当于没有来源地补能。

继续固定物质的 map 能改善反馈估计，却不会更新物质；因此它能澄清失败是否受内层漂移影响，不能单独解决外层能量方程。相邻辐射场接近不意味着大项相消后的净加热同样稳定，更不意味着目标气体热能为正。

最终需要先取得一个被接受的物质步，再收敛代表柱，并验证内层精度、能量闭合及网格敏感性。之后才能覆盖半径/轨道相位定义域，生成角分辨表面强度 I_nu，并接入观察者积分。局域发射系数 j_nu 是转移方程的源项；它需经过吸收、散射与边界条件才决定涌现强度，不能把当前 j_nu 或未闭合的 I 工作态交付为自洽整盘光谱。现有结果不能给出可信的全项目完成时间。

## 7. 平台 Claude 只读复评与人工筛选

已通过 `claude -p --tools ""` 取得教学草稿及质疑，原输出留在 Mac `outputs/review-20260919/claude-review.json`。采用其要求明确基态分母、绝对范数、链内趋势及不同预算的建议。未直接采用以下错误论断：

- “内层迭代不能使非正目标变正”：不成立。迭代改变加热及率，计算得到的目标热能符号可以改变；必须讨论固定点反馈下的目标，不能把有限精度的负值当最终证明。
- “两个端点可给出噪声地板”：不成立，只能得到一次漂移及跨路径差异，不能自动得到误差界。
- “步长越小响应越坏在光滑问题不自然，因此更像噪声”：不是可靠归因。响应可以非单调，当前也没有共同内层误差控制。
- “范数比值相近说明单胞主导”：仅由两个比值相近无法推出集中度。
- “7200 s 是 map 耗时上限，两个 map 应并行”：混淆反馈资源门和 map；实际 map 串行，worker 并行频块。
- 草稿把第二个输入的算子差写成 `M(I_base)-I_base`；正确应为 `M(M(I_base))-M(I_base)`。前者是第一个输入的算子差。
