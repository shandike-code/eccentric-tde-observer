## 下一步与判据

反馈每 4 张一轮，将给出 R ≈ 1.25e-4 → 1.16e-4 区间上的四个新 (R, 配对原子加热量) 点。要看的是：

1. 加热量是否继续按 α=0.0625 家族已实测的 `H ∝ R^1.6` 下降（斜率由同 run 内 log-log 拟合给出，不外推成"再跑 N 张就过门"）。
2. 非物理（无正气体热能）单元是否保持 0 个——该家族目前是唯一全程物理的候选。
3. 若出现像 confirm run 那样的回升，则说明该量不由 R 控制，内层精度路线到此为止，必须转向阶段 D 的响应闭合/有界回溯。

任何失败（非零退出、OOM、超时、未知状态）都由监督器停止自动续交，保留进度与部分证据，人工检查后再决定是否恢复。
