## 1. 71878 的 5 秒失败已定位：不是血缘或实现差异，是末位舍入经 log 放大

差异的分布把性质钉死了：

- `energy` 与 `hydrogen_logratio` 两个分量**差恰好为 0**；
- 差异只在 `helium_logratio`（3.81e-12）与 `electron_logratio`（7.78e-12），最差元素在 cell 123，量级 6.86e-4；
- 对应的中间量本身只差 1 ulp：`response_helium_fraction` 最大 1.11e-16（195/384 个元素）、`response_hydrogen_fraction` 最大 4.96e-24（2/256）、`response_temperature_k` 13/128 个单元差 1 ulp（相对 2.27e-16）。

机制是明确的：局域布居/温度求解在最后一位分叉（不同 libm/openblas），codec 的 `log` 变换把 1 ulp 的相对差放大成 1e-12 量级的绝对差。残差自身尺度是最大分量 3.4593、L2 15.5889，观测差异是它的 2.2e-12。

原判据 `atol=3e-13` 是逐元素的，对量级只有 1e-4 的分量等于要求两平台逐位一致，这在跨平台重放上不可达。修订为两级：

- **入口判据**：尺度锚定，`max(ΔL2/L2尺度, max|Δ元素|/max|元素|) ≤ 1e-9`。实测 0.00225（445 倍余量）与恒等式 0.00023。
- **严格逐位判据**：保留在记录里。Linux 不通过（25.34 倍）、Mac 通过。两者并列写出，不互相替代，也不作为物理接受条件。

同类问题第二次出现于代数恒等式 `recover_equation_residual` 对直接能量方程的比较（Mac 上余量仅 2.6 倍），同样改为尺度判定。基态身份链在这一步之前已经全部通过：`target = base + stored` 最大差 0.0、编解码往返 0.0、账本拆分自检 0.0、非物理响应单元 0。

## 3. 同口径内层精度阶梯：加热量随 R 的实测关系

从三个 run 的 22 个回合提取配对的原子加热量（`atomic_heating_volume_l1`，门 1e-3）与两端点辐射残差：

| run | 回合数 | R 范围 | 加热量范围 | 同一 run 内 log-log 斜率 | 非物理单元走势 |
|---|---|---|---|---|---|
| cont64 α=0.0625 | 16 | 1.872e-04 → 1.259e-04 | 5.862e-03 → 3.134e-03 | 1.635 | 6 → 0（单调减少） |
| scale32 α=0.03125 | 4 | 1.115e-03 → 3.195e-04 | 6.752e-03 → 7.222e-04 | 1.821 | 34 → 43（增加） |
| confirm α=0.03125 | 2 | 2.779e-04 → 2.585e-04 | 5.056e-04 → 1.217e-03 | 不适用 | 43 → 43 |

三个事实必须一起读：

1. α=0.0625 家族里加热量随 R 平滑下降，斜率约 1.6，非物理单元从 6 个减到 0 个。这是唯一有平滑收益证据的方向。
2. α=0.03125 家族里，辐射精度提高反而让非物理单元从 34 个增加到 43 个。该家族的失败是**响应闭合**在 60.8% 质量上离开物理域，不是辐射没收敛；再压 R 不解决它。
3. confirm 的第 1→2 回合在 R 几乎不变（2.779e-04 → 2.585e-04）时加热量回升 2.4 倍（5.056e-04 → 1.217e-03）。这说明该量**不由 R 唯一决定**，与 71816 的定位一致：两轮之间逐块绝对变化总量下降 10.12%，但块间相消从 49.221 降到 18.377，净 L1 因此上升。斜率 1.6/1.8 只是同一 run 内的经验描述，不能外推成"再跑 N 张就能过门"。

### 3.1 非物理单元的机制（用已归档账本，零新算力）

账本定义是 `radiative_energy = dt·q/ρ`、`total_old = gas_old + ion_old`、`remaining = total_old + radiative_energy − ion_new`。观测到的每行都满足 `remaining/gas_old = 1 + radiative/gas_old` 到所列精度，且电离能变化项可忽略（`delta_ionization/gas_old ≈ −1.7e-10`）。因此非物理单元的含义是**净速率项为负**，即冻结场在该单元给出的是净冷却：

| run（最差 cell 106） | α | remaining/gas_old | dt·q/(ρ·gas_old) | Δionization/gas_old |
|---|---|---|---|---|
| cont64 previous/final | 0.0625 | +0.0287 / +0.0308 | −0.9713 / −0.9692 | 3.27e-09 |
| backtrack-v2 previous/final | 0.03125 | −1.5736 / −1.5376 | −2.5736 / −2.5376 | −1.11e-10 / −1.03e-10 |
| scale32 previous/final | 0.03125 | −2.0644 / −2.0661 | −3.0644 / −3.0661 | −1.74e-10 |

也就是说，α=0.0625 的最差单元在一个 dt 内失去 97% 的气体热能（仍为正，余 2.9%），而 α=0.03125 的同类单元失去 257%–307% 的气体热能，目标温度不存在。让最差单元保持为正所需的气体热能倍数分别是 1.97 与 4.07，即在冻结场与固定 dt 下，α=0.03125 的该类单元需要把 dt 缩小约 4 倍（到 ≈218 s）才可能落到正温度域。这是诊断量，不是把 dt 调小来过门的提议：改 dt 会同时改变辐射场与整个问题。

由此可以定量地说：α=0.03125 的失败不是"辐射还不够收敛"，而是固定物质候选与冻结辐射场在一次物理步内不自洽——净冷却超过了可用气体热能。继续为该家族增加 map 不会改变这一点（实测反而从 34 个单元增加到 43 个）。

## 4. 现状与下一步的可选动作

现状：基态同尺度诊断已建立并入库；没有后台作业（71918 已完成，队列空）；未接受物质步、未生成自洽柱或全盘 I_ν。

按证据，下一步只有两条站得住的路：

**A. 有界内层精度实验（cont64 家族）。** 在 α=0.0625 上再跑有限张 map（例如 16 张，4 核约 1.5 小时），只检验一件事：加热量是否继续按约 R^1.6 下降、非物理单元是否保持 0。它不承诺过门，也不改变任何验收门。成本已知、有界、可中断。

**B. 响应闭合诊断（已完成，见 3.1）。** 结论：α=0.03125 家族的非物理单元来自净冷却超过可用气体热能，最差单元需要 dt 缩小约 4 倍才落回正温度域；该失败随辐射精度提高而扩大，因此 A 若针对 α=0.03125 没有意义。

于是 A 的适用范围被收窄为一件事：在 α=0.0625（唯一全程物理、且非物理单元已随精度归零的候选）上再跑有限张 map，检验加热量是否继续按约 R^1.6 下降。它不承诺过门；若继续下降，α=0.0625 就是越过 1e-3 门的候选路径，若出现像 confirm 那样的回升，则说明该量不由 R 控制，必须转向阶段 D 的响应闭合或方向回溯。
