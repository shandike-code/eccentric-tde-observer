# 新物质方向的有界对照批次

## 决策依据与明确改变

74472 原正式 16 门中只有 L2、质量加权收缩失败，新基态对照仍不下降。74663 逐位重放确认结果，旧方向的本次有限割线不预测正步长下降。因此不继续沿同一方向机械减半；新建一个方向试验，同时保留旧正式判决和全部旧源文件。

记原编码基态为 x0，74663 重放的基态 final 响应残差为 R0。新方向 d_new=R0，候选 x(alpha)=x0+alpha*d_new，alpha 固定为 1/256 和 1/512。这是阻尼 Picard 提案，不是精确 Newton 方向，没有保证下降。R0 来源于 74472 零位移控制的 final 反馈，准备时在 Linux allocation 内重新调用原响应，必须与审计保存的 residual.npy 逐位相同。

旧 finite_direction 被新方向明确替换；旧 base_encoded_state、base_residual、物理旧时间层、phase1367、dt889.419892762322秒、密度、能量定义、网格、原子率、转移核不变。正式接受仍使用旧冻结 base_residual 及原 16 门；新零控制比较另存，绝不替换分母或翻改旧失败。每个候选仍需真正的物质响应正性，解码正性不能替代。

## 一次 allocation 的任务安排

run `outputs/hpc/response-direction-20260921`，32 CPU、128 GiB、16 worker、4 小时上限。固定最大 18 map/5 对反馈：

1. `control`：同 x0、2 张完整 map、1 对零位移反馈。数值初猜取 74472 B-base 最后输出，先在 allocation 核大态 SHA。原辐射/边界门、五类反馈稳定性门及两个物质响应物理域均通过才进入候选。零位移无接受权限。
2. `full`：新方向 alpha=1/256，最多 8 map，在 map3/4、7/8 输入端点各结算一对原正式反馈。
3. `half`：新方向 alpha=1/512，同样最多 8 map/2 对反馈。两候选使用与 control 相同的初始数值 seed，不能继承其收敛结论，也不能因为迭代次数相同就宣称误差相同。
4. 每轮自动生成与新 control previous/final 的完整残差比较和原独立能量账本，归档后自动衔接。原正式接受即终止全批，状态 `formal_acceptance_requires_review`；需人工审阅新对照及内层敏感性，不自动串接下一物质时间步。

候选物理域失败时该候选停止，保留原失败层与账本，然后按预案测试另一较小幅度；不能删失败层。若只是有限精度下收缩或稳定性失败，按预声明继续到第二轮，预算耗尽停止。资源/代码故障终止全批，不能当科学拒绝后继续。控制态不稳/物理域失败终止全批。

欠反馈/账本先于任何新 map，信号只在当前 batch 提交后停止派发；恢复沿同总预算，不自动重提。每个 run 自己拥有 trial、配置、初始化证明、state、反馈目录。新 trial 在初始化前写入，逐字段回读、native 镜像及初始化 seed 三重核验。原 6 GiB worker 守卫与独立 /proc 观测都保留，使用已验证轻量中继。源码/小输入/方向/seed SHA 写入声明，旧文件不原位修改。

## 成本与验收范围

按近期每 map 约 2.5–3 分钟、每对反馈约 6 分钟，18 map/5 对反馈的数值核心约 75–85 分钟；另有初始化、完整哈希、归档、共享盘 I/O 及排队，预计约 1.5–2 小时，4 小时只是上限。失败门或接受门触发后可能提前结束，不为了用满 allocation 填充计算。

此批的目标是检验新方向和两个固定幅度能否给出可靠下降，不是完成代表柱或整盘。即使所有原门通过，也只得到一个待审阅物质步。相邻反馈漂移和不同历史差异继续按观测差量报告，不作为严格真误差界。
