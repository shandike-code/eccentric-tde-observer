## 1. 错误

原报告用 `per_depth.reshape(128, 32).sum(axis=1)` 把 4096 个辐射子胞归入 128 个物质层。

**真实的映射不是这样。** 适配器
`scripts/phase7b9_formal_feedback_pair_adapter.py:593` 是：

```python
name: np.mean(array.reshape(256, 16, *array.shape[1:]), axis=1)
```

即 4096 子胞 → **256 个全柱 parent 层，每层 16 子胞**；再由
`scripts/phase7b7a_feedback_coefficients.py:570` 取 `half_* = parent[:128]`。
**两个半柱互为镜像**，折回物质层是 `parent[:128] + parent[128:][::-1]`，
**不是**相邻 32 个子胞合成一层。

### 复现（本机独立验证）

```python
perturbation = np.zeros(4096); perturbation[96*16:97*16] = 1.0
parent  = perturbation.reshape(256, 16).mean(axis=1)   # 非零索引 [96]   ← 真实
old     = perturbation.reshape(128, 32).sum(axis=1)    # 非零索引 [48]   ← 我的错误
mirror  = ...subcells 159*16:160*16...                 # 折回后仍为 96   ← 镜像正确
```

**单层扰动被定位到 48 而不是 96。** 已加回归测试
`tests/test_material_energy_ledger.py::test_parent_96_perturbation_localises_to_96_not_48`
与 `::test_mirrored_perturbation_folds_to_the_same_material_layer`。

## 2. 撤回的结论

以下原报告结论**全部撤回**，不得再作为机制判断依据：

| 原报告说法 | 状态 |
|---|---|
| 「物质层 96 只占分子的 **0.109%**」 | **撤回**。正确值见下表 |
| 「加热变化与物理域失败**空间不重合**」 | **撤回**。正确表述：**存在部分空间重合** |
| 「贡献最高的五个物质层 60, 67, 71, 56, 68」 | **撤回**。层号本身因错误归层而无效 |
| 「两套网格没有确定映射关系」 | **撤回**。映射关系明确存在，见 §1 |

Mac 侧指出「`half_*` 不是彼此的降采样」这一说法与实际数组不符——这一条也撤回：
`half_*` 确实是 4096 网格经 256 parent 再取前半的**降采样结果**，链式关系完整。

## 3. 重算值（三个端点，两种正确口径）

分子为已含宽度权重的贡献，按 (256,16) **求和**（不再乘宽度）。
- **折回口径**：`folded = parent[:128] + parent[128:][::-1]`，分母除**全柱**分子总和
- **前半柱口径**：只取前半柱，分母除**前半柱**分子总和
- **混用口径**：前半柱值却除全柱分母（明确标注，属另一口径）

| 端点 | 全柱分子总和 | 前半柱 | cell96 折回值 | **折回占全柱** | **前半柱值占全柱** |
|---|---|---|---|---|---|
| warm | 3.801525e+11 | 1.900762e+11 | 5.951267e+09 | **1.565495%** | **0.782747%** |
| round1 | 3.691718e+11 | 1.845859e+11 | 5.782857e+09 | **1.566441%** | **0.783220%** |
| round2 | 3.581146e+11 | 1.790573e+11 | 5.607720e+09 | **1.565901%** | **0.782951%** |

`前半柱/全柱 = 0.500000`（三个端点都精确到 6 位）——镜像对称的印证，
也是「折回占全柱」与「折回占前半柱」两数相同的原因。

**贡献最高的五个折回物质层**（原报告写 60/67/71，全错）：

| 端点 | 折回顶层 | 占全柱 |
|---|---|---|
| warm | 120, 112, 121, 119, 118 | 14.19866% |
| round1 | 120, 112, 121, 119, 118 | 14.32147% |
| round2 | 120, 121, 112, 122, 119 | 14.43485% |

### 与失败层的重合度

| 端点 | previous 失败层 | final 失败层 |
|---|---|---|
| warm | 16 个：62–65, 73–75, 85, 86, 95–97, 104–107 | 14 个：62–65, 73–75, 85, 86, 95–97, 105, 106 |
| round1 | 14 个：62–65, 73–75, 85, 86, 95–97, 105, 106 | 13 个：62–65, 73–75, 86, 95–97, 105, 106 |
| round2 | 9 个：63, 64, 73–75, 96, 97, 105, 106 | 9 个：同上 |

**正确表述**：加热变化并非全部集中在物理域失败层，两者存在**部分空间重合**
（cell96 本身是失败层之一，占加热变化约 1.57%）。该结果**既不能证明**两者独立，
**也不能单独证明**共同原因。

## 4. 原报告哪些结论仍成立、哪些因修正而改变

**不受归层错误影响、仍然成立**（它们的算术本来就不依赖深度分组）：

1. 失败机制：深层净冷却使 `dt·Q/ρ` 超过旧气体热能，目标总能量跌破新电离能。
2. Δ电离能可忽略（相对 7.9e-11）。
3. 账本口径自洽：气体/电离能拆分与原函数**逐位相同**（差 0.0）；守恒残差 ~2e-16。
4. 六个端点的负热能报错与五类正式反馈指标**逐一复现**（修正版工具与
   `feedback_summary.json` 一致到 1e-15）。
5. 净加热在局部是两个几乎相等的大量的差（中位约毛额的 0.16%）。

**因诊断修正而改变**：

1. 深度定位全部数值与层号（§3）。
2. 「空间不重合」→「部分重合」。
3. 多分量指标的分子/分母配对：原报告展示的 `2.041055e+17 / 2.631910e+21` 来自**不同分量**。
   正确配对是 `2.041055e+17 / 1.060668e+21 = 1.924311e-4`。修正版同时输出全部三个分量
   的分子、分母、比值（`component_numerators` / `component_denominators` / `component_ratios`）。

**同时纠正的表述**（Mac 侧指出，我接受）：

- 「几何衰减永远到不了零」**不适用于**判断剩余热能是否穿零——它的极限符号未知。
- 两个迭代阶段的收缩比**不能证明**「越接近固定点一定越慢」这一普遍规律。
- 发射项固定源于**当前固定物质候选及其系数**，不能等同于热力学更新所用的旧时间层。
- 「相消因子中位数 × 全局归一化吸收变化」**不是**正式加热加权指标的等式；
  它只描述局部机制，不能当作定量因果证明。修正版已在
  `absorption_emission_cancellation.interpretation` 中写明这一点。
- `charge_neutral_backward_euler_step` 与物质响应默认二分次数**都是 96**，
  先前怀疑的「默认参数不一致」不成立。

## 5. 账本输出字段修正

| 问题 | 原状态 | 修正 |
|---|---|---|
| `old_hydrogen` / `old_helium` 实填 `new_h` / `new_he` | 字段名与内容不符 | 同时输出 `old_*` / `new_*` / `delta_*` |
| 先按绝对热能选最差层，再算该层相对缺口 | 不等于全层最大相对缺口 | `absolute_worst` 与 `relative_worst` 分别给出准则、索引与值 |
| 多分量取最大分子 / 最大分母 / 最大比值 | 三者可能来自不同分量 | 输出最差比值所属**同一分量**的分子与分母，并保留全部分量 |
| 全零/未定义 | 可能除零、写非有限值 | 用 `null` + 明确语义；`json.dumps(..., allow_nan=False)`；不加 floor |
